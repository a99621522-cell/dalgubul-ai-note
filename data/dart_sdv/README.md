# data/dart_sdv — SDV 연구보고서용 DART 원자료(사이트와 분리)

「현대·기아차의 SDV가 지역 자동차 부품회사에 미치는 영향과 대책 — 대구·경북」 연구보고서에 쓸 원자료(운영자 지시 2026-10-20).
사이트는 이 폴더를 읽지 않는다. 사이트 산출물(`scripts/data/company_financials*.csv`, `data/dart/*.csv`)과 섞지 않는다.

- 범위: 경상북도 본사 회사만(운영자 지시 2026-10-20 '경상북도만 하면 돼' — 대구 본사 회사는 사이트 수집기 자료(`scripts/data/company_financials*.csv`·`company_rnd.csv`)에 이미 있음)
- 만드는 곳: `scripts/collect_dart_sdv.py` ← 대상 목록 `scripts/data/sdv_targets.csv`(고쳐서 푸시하면 `.github/workflows/dart_sdv.yml` 이 다시 돈다)
- `targets_resolved.csv` — 입력 회사명 → DART 고유번호(corpCode.xml 이름 정확 일치, 동명이면 상장·본사 대구·경북 우선), 종목코드·시장·본사 주소·업종코드(기업개황), 매칭 방법·비고(비상장·본사 대구경북 아님·결산월). '추가 발견' = 목록에 없지만 본사 경상북도 + 업종코드 30xxx(자동차 및 트레일러 제조업) 상장사
- `financials.csv` — 단일회사 전체 재무제표(fnlttSinglAcntAll)의 주요 계정: 매출액·영업이익·당기순이익·자산·부채·자본총계·판매비와관리비, 계정명에 '연구개발'·'경상연구'가 든 손익 계정. 사업보고서 2023·2024·2025(연간·기말), 2026 반기보고서(손익은 2분기 3개월과 1~6월 누적 두 줄, 재무상태는 6월 말). 연결 우선, 없으면 개별. 계정명은 공시 그대로, 금액은 원
- `rnd.csv` — 연구개발비: 2025 사업보고서·2026 반기보고서 원문의 '연구개발 활동' 표 합계 행·매출액 대비 비율 행(공시 단위 → 원). 사업보고서 열 = 2025·2024·2023 연간, 반기보고서 첫 열 = 2026년 1~6월(뒤 열은 '표 머리' 글자로 대조). 표 모양이 달라 못 읽은 회사는 로그에 '못 찾음'
- `financials_all.csv` — 같은 보고서의 모든 계정 행(재무상태표·손익계산서·포괄손익·현금흐름·자본변동), 당기·전기 금액 그대로
- `company_cache.json` — 기업개황 캐시(회사명·종목코드·시장·본사 주소·업종코드·설립일·결산월만, 대표자 등 개인정보 없음)

주의: 연구개발비는 대부분 회사가 손익계산서가 아니라 주석·사업의 내용에만 적어 `financials.csv` 보다 `rnd.csv` 를 본다. 결산월이 12월이 아닌 회사는 '연도'가 사업연도다.
