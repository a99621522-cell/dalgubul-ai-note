# data/funds — 대구시가 출자·조성한 창업·벤처 펀드

`daegu_funds.yml` 한 파일. `/startups/`(메뉴 '창업·벤처')의 「대구시가 출자·조성한 창업·벤처 펀드」 절이 `src/lib/funds.ts` 로 읽는다.

- `plans` — 조성 중·계획(2026): 이름·상태·규모(계획)·출자 구성·대상·출처
- `regional` — 운용 중인 지역 펀드(DASH '지역 운용 펀드' 게시: 펀드 규모 `size_eok`·운용사 `gp`·투자 대상·문의 기관). 발표가 확인되면 `formed`(결성 연도·출자 구성)와 `sources`(언론 보도는 `press: true` — 조사 기록용, 사이트에는 매체 이름·링크를 싣지 않는다, 운영자 지시 2026-10-08)
- `city` — 대구시 출자펀드(DASH '대구시출자펀드' 게시: 운용사·투자 대상·투자 규모 `ticket`, 상시 모집)

원칙: 공개 자료의 값 그대로(억 원), 평가·순위 없음, 피투자 기업 명단·투자 실적은 공개 자료에 없어 싣지 않음, 담당자 전화는 싣지 않음.
갱신: DASH 두 페이지(`dash.city`·`dash.regional`)를 다시 읽어 항목을 맞춘다. 이 세션 환경은 startup.daegu.go.kr 접속이 막혀 있어 `site_probe.yml`(url, text=true)로 러너가 본문을 로그에 찍는다(간헐적 시간 초과 — 다시 실행).
