# 지방재정365 대구 세출 (내부 계산용)

`scripts/fetch_lofin.py` + `.github/workflows/lofin.yml` 이 행정안전부 지방재정365 재정 데이터셋(로그인 없는 Sheet 의 CSV 내려받기와 같은 요청)에서
대구(본청 2700000·구군 27xx000) 행만 받는다. 금액 단위 원, 값은 그대로.

| 파일 | 데이터셋 | 받은 연도 |
|---|---|---|
| nature_settle.csv | 성질별 단체별 세출결산(순계) | 2002~2021 (목록은 2024까지라고 적혀 있으나 대구 행은 2021까지 받힘 — 확인 필요) |
| func_settle.csv | 기능별 단체별 세출결산(순계) | 2010~2024 |
| struct_func_settle.csv | 구조별 기능별 세출결산(총계) | 2010~2024 |
| struct_func_budget.csv | 구조별 기능별 세출예산(총계·순계) | 2008~2026 |

**사이트에 싣지 않는다**(운영자 지시 2026-09-30: 대구시 예산 삭제). GRDP 기여 계산 초안(docs/drafts)에서 세출을 GRDP 지출 항목에 대응시킬 때만 쓴다.
