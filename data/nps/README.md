# data/nps — 국민연금 가입 사업장 내역 (대구)

`scripts/collect_nps.py` 가 공공데이터포털 "국민연금공단_국민연금 가입 사업장 내역"(월별)에서 대구 사업장만 골라 `YYYYMM.csv` 로 둔다.
열: 자료생성년월, 사업장명, 사업자등록번호(포털이 앞 6자리만 제공), 사업장가입상태코드, 사업장도로명상세주소, 사업장지번상세주소,
법정동주소광역시도코드, 사업장업종코드, 사업장업종코드명, 적용일자, 재등록일자, 탈퇴일자, 가입자수, 신규취득자수, 상실가입자수.
고지금액 등은 저장하지 않는다.

쓰는 곳: `build_stats.py`(고용 인원 = 가입자수, 취득·상실, 신규·탈퇴, 24개월 시계열) · `import_extra.py`(팩토리온에 없는 사업장 → 산단 외 기업).
받는 방법: GitHub Actions `nps.yml`(매월 6일, 또는 수동 실행에 api_url 입력) 또는 로컬에서
`python3 scripts/collect_nps.py --file <포털에서 받은 전국 CSV>`.
