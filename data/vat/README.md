# data/vat — 지자체 부가가치세 매입세액 점검기 규칙

페이지 `/vat/`(메뉴 '사업·지원 › 지자체 부가세 점검기', 운영자 지시 2026-10-27)가 쓰는 규칙 파일.

- `rules.yml` — ① 지자체 사업의 과세·면세(법 제26조 제1항 제19호, 시행령 제46조) 시설 유형표 ② 매입세액 공제·불공제·공통매입세액 안분·재계산·신고 규칙(조문 번호·뜻) ③ 지출 건 판정기의 선택지 ④ 위탁 시설 운영에서 자주 나오는 지출 ⑤ 신고 전 점검표.
- 읽는 코드: `src/lib/vat.ts`(빌드 때) → `src/pages/vat/index.astro`(표·설명, 규칙을 JSON 으로 페이지에 넣음) → `src/scripts/vat_check.ts`(브라우저 판정·계산, 서버·AI 호출 없음).

## 원칙
- 조문 번호와 조문의 뜻만 적고 해석·평가를 더하지 않는다. 판정은 참고용이며 신고 책임은 담당자에게 있다고 페이지에 적는다.
- 확신이 없는 항목은 `verify: true` → 화면에 '원문 확인 필요'. 국가법령정보센터 원문 링크(`law_url` 틀, 예 `https://www.law.go.kr/법령/부가가치세법/제39조`)와 국세청 유권해석으로 담당자가 확인한다.
- 이 세션 환경은 law.go.kr 이 막혀 있어 조문 글자를 직접 대조하지 못했다(2026-10-27). `config/guidelines.yml` 에 부가가치세법·시행령·시행규칙(`vat-act`·`vat-decree`·`vat-rule`)을 넣어 두었으므로 `guidelines.yml` 워크플로가 본문을 `data/guidelines/` 에 받으면 그 본문으로 `verify` 항목을 검토하고 표시를 내린다.
- 금액·비율 기준(면세비율 5%·공통매입세액 500만 원·5만 원·재계산 5%p·등록 20일·보관 5년)은 법령 값이며 바뀌면 이 파일만 고친다.
- 개별 기관의 신고 자료·내부 문서 값은 넣지 않는다.
