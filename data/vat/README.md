# data/vat — 지자체 부가가치세 매입세액 점검기 규칙

페이지 `/vat/`(메뉴 '사업·지원 › 지자체 부가세 점검기', 운영자 지시 2026-10-27)가 쓰는 규칙 파일.

- `rules.yml` — ① 지자체 사업의 과세·면세(법 제26조 제1항 제19호, 시행령 제46조) 시설 유형표 ② 매입세액 공제·불공제·공통매입세액 안분·재계산·신고 규칙(조문 번호·뜻) ③ 지출 건 판정기의 선택지 ④ 위탁 시설 운영에서 자주 나오는 지출 ⑤ 신고 전 점검표.
- 읽는 코드: `src/lib/vat.ts`(빌드 때) → `src/pages/vat/index.astro`(표·설명, 규칙을 JSON 으로 페이지에 넣음) → `src/scripts/vat_check.ts`(브라우저 판정·계산, 서버·AI 호출 없음).

## 원칙
- 조문 번호와 조문의 뜻만 적고 해석·평가를 더하지 않는다. 판정은 참고용이며 신고 책임은 담당자에게 있다고 페이지에 적는다.
- **원문 대조(2026-10-27)**: `guidelines.yml` 워크플로(입력 only=vat-act,vat-decree,vat-rule)로 법·시행령·시행규칙 본문을 `data/guidelines/` 에 받아 조문마다 맞췄다(`verified:` 에 대조일·법령 시행일). 바로잡은 것은 파일 머리 주석에 적었다(재계산 영 제83조, 과세사업 전환 영 제85조, 안분 생략 3호의 뜻, 주차장 운영업은 열거 업종 아님, 면세공급가액에 보조금 포함 등).
- 표시 두 가지 — `verify: true` = 조문 원문을 아직 대조하지 못함(지금은 국세기본법 제45조의2 뿐, 이 법은 창고에 없음) → '원문 확인 필요'. `interp: true` = 법령 글자가 아니라 표준산업분류·국세청 유권해석에 달림(행정재산 사용허가·종량제 봉투·대관·광고 게시료·파크골프장·야영장) → '유권해석·분류 확인'. 조문 링크는 `law_url` 틀(예 `https://www.law.go.kr/법령/부가가치세법/제39조`).
- 법령이 개정되면 워크플로를 다시 돌려 본문을 받고 같은 방식으로 대조한다(세션 환경은 law.go.kr 차단).
- 금액·비율 기준(면세비율 5%·공통매입세액 500만 원·5만 원·재계산 5%p·등록 20일·보관 5년)은 법령 값이며 바뀌면 이 파일만 고친다.
- 개별 기관의 신고 자료·내부 문서 값은 넣지 않는다.

## presets/ — 예시 설정(운영자 지시 2026-10-27 '달성군이 위탁 주는 시설을 넣는 것은 어때? → 만들어')
- `presets/<key>.yml`: 기관 설정 마법사 2단계의 「○○ 예시 불러오기」. **공개 자치법규(국가법령정보센터)로만** 시설 이름·유형·조례 근거를 적고, 운영 방식(군 명의 대행 / 수탁기관 자기 사업)·사업자등록번호·매출은 넣지 않는다 — 불러온 시설은 운영 방식 '확인 필요'(`run: unknown`)로 들어가 담당자가 위·수탁 계약대로 고른다. 과세 여부는 rules.yml 유형 기준 참고 표시이며 기관의 공식 판단이 아니다.
- 첫 사례 `dalseong.yml`(대구광역시 달성군, 2026-10-27): 시설관리공단 설립 조례 제19조(사업)·제20조(대행사업) + 체육시설·주차장·파크골프장·자연휴양림·유스호스텔·레포츠밸리·달성문화센터·문화회관·교육문화복지센터·청소년수련시설·선비체험관·치유의 숲·관광객 이용시설·사문진 역사공원·농수산물종합유통센터 조례에서 17곳. 조례 별표의 개별 체육시설·주차장 이름은 조문에 없어 한 줄씩 두고 「같은 유형 하나 더」로 나눈다. 같은 날 2차(운영자 '달성군 의회에 위탁동의안 받아야 하니 그쪽도 조사해봐'): 공단 누리집은 `dssiseol.or.kr`(시설 목록·조직도 '공단관리시설')이고, 군의회 '의안 처리 현황'(`council.dalseong.go.kr/content/info/processing.html?f_bill_title=위탁`, 간헐적 연결 재설정이라 재시도)에서 민간위탁 동의안 목록을 읽어 시설 43곳(공단 관리 34·민간위탁 6·확인 3, `op` 칸)으로 늘렸다. 의회 동의안은 민간위탁에만 있고 공단 수탁(대행사업)은 위탁계약·군수 승인(제3자 재위탁만 의회 동의)이라 의안 목록에 없다. 의안 상세(BillView)에는 처리 일자만 있고 수탁자·기간·사용료 귀속은 없다. `findings` 가 설정 화면 '예시의 출처와 조사 결과'에 보인다. 지방공기업 경영공시(cleaneye.go.kr)·의회 심사보고서는 이 세션에서 안 열리거나 항목이 없었다. 같은 날 3차(운영자 '회의록 제안설명도 읽어서 수탁자랑 기간 채워봐'): 군의회 회의록(제9대, `council.dalseong.go.kr/content/minutes/case.html` 안건 검색 → `mntViewer.php`)의 민간위탁 동의안 제안설명 10건에서 수탁자(기관 이름만)·위탁 기간·제안설명에 적힌 위탁사업비를 `contractor`·`term` 으로 옮겼다(문화회관 달성문화원 2026~2028 · 문화도시센터·선비체험관·하빈PMZ (재)달성문화재단 · 도시재생지원센터 사회적경제협의회 · 근로자복지관 공개모집 · 보훈회관 보훈단체협의회 · 군청 카페 정인장애인복지회 2023-12-30~2026-12-29, 같은 회의록의 종합사회복지관·북부노인복지관도 추가 → 48곳). 설정 마법사는 `contractor` 를 수탁기관 칸에 '(협약서 확인)'을 붙여 넣고 `term` 을 비고 앞에 적는다. 발언자·공무원 성명은 적지 않는다. 마비정 벽화마을 리뉴얼은 사업 위탁이라 시설에 넣지 않았다.

## 세무사 관점 보강(2026-10-27)
- `rules.yml`: `card.practice`(사업용 신용카드 등록 등 실무 절차, 조문 아님), `filing.claim`(경정청구 — 국세기본법 제45조의2 를 law.go.kr DRF 로 직접 대조해 `verified.basic: "2026-10-02"`, `filing.verify: false`), `form_version`(신고서 별지 제21호서식 확인 판).
- 기관 설정 시설에 `fee`(수탁기관 자기 사업일 때 우리 기관이 받는 것: taxable/free/unknown)·`decision`(확인 결과·근거). 기록 행에 `subsidy`·`fix_due`(수정세금계산서 기한, 시행령 제70조 제1항 제6호). 신고 기록 `groups[].basis`(안분 기준 supply/purchase/planned/area, 시행령 제81조 제4항).
- 새 화면 `/vat/review/`(지난 신고 점검·경정청구 후보). 설계 기록은 `docs/design/vat-first-timer.md` 끝 표.
- 2차(같은 날): `/vat/review/` 는 공급자별 집계 비교(합계표 서식)와 기한후신고 구분, 신고 준비는 안분 기준 잠금·과세사업 전환 매입세액 계산기(영 제85조), fee 선택지에 `paid_check`. 설계 기록 같은 파일 '2차 평가' 표.
- 서식 모양 결과(같은 날): `src/scripts/vat_forms.ts` — 별지 제21호·39호(1)·16호(1)·22호·25호·17호 칸 배치. 기록 행에 `sup`·`sreg`(붙여넣기의 공급자 상호·등록번호), 신고 기록 `sales[]` 에 간주임대료 입력값. 설계 기록은 `docs/design/vat-first-timer.md` 끝.
- `revenue_items`(같은 날, 절감 사유 ①): 세외수입 27항목 점검표 — `/vat/discover/` 가 읽음. 항목 추가는 여기만(status·type·basis·deduct).
- 수탁기관(공단) 기준(같은 날): `facilities[].contractor_status/contractor_note`, `revenue_items[].contractor_status/contractor_note/only`. 지자체 기준 `status` 와 나란히 두고, 설정의 기관 종류로 고른다.
- 세무회계법인 관점 검토(같은 날, 운영자 '권장하는 순서대로'): `rules.ratio_mgmt`(실지귀속 입증 방법 4가지 `proof` — 기록 행 `evid` 키와 같다, 면세 공급가액 구성 `exempt_supply`, 취득 시기 `timing`), `rules.build`(예정사용면적·조기환급·등록 전 매입세액·토지분, `refund_days` 25/15/30일), `rules.penalty`(과소신고 10%·무신고 20%·납부지연 1일 22/100,000·5년 상한·수정신고/기한후신고 감면표·지연수취 5/1,000 — 국세기본법 2026-10-02 시행 판·시행령 2026-02-27 시행 판 DRF 대조, `verified.basic_decree`). 법령 값이 바뀌면 여기만 고친다. 읽는 곳: `vat_forms.ts renderRatioMgmt`, `vat_build.ts`, `vat_penalty.ts`·`vat_rules.ts penaltyCalc`·`earlyRefundSchedule`, `vat_schedule.ts`. 설계 기록은 `docs/design/vat-first-timer.md` 끝 표.
- 세무회계법인 관점 2차(같은 날): `rules.admin_common`(본청·행정 공통은 영 제81조 제4항 순서, 유권해석 확인), `rules.subsidy_settle`(보조금 정산 연계, 조문 없음), `rules.develop`(공영개발·분양 — 토지 면세·건물 과세·토지 관련 불공제·공통비 예정공급가액 안분·중간지급조건부·조기환급·주택 제외), `rules.entity_unit`(사업자 단위 과세 전환, 법 제8조 제3·4항), `rules.agency_contract`(대행 협약서 점검표 7개). 읽는 곳: `vat_prepare.ts`(admin 묶음·보조금), `vat_forms.ts`(22호 3-1 표·`renderEntityUnit`), `vat_review.ts`(안분 입력), `vat_setup.ts`(협약서), `vat_develop.ts`.
