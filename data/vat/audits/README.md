# 정부합동감사 결과 PDF 의 부가가치세 발췌

`scripts/fetch_audit_vat.py <nttId …>` 가 행정안전부 「감사(감찰)계획 및 결과공개」 게시판(bbsId=BBSMSTR_000000000002)의 정부합동감사 결과 PDF(공개본, 5~8MB)를 받아 '부가가치세·부가세·매입세액·세금계산서' 가 든 지적 항목만 `<nttId>.txt` 로 남긴다(원문 PDF 는 저장하지 않음). 목록은 `index.json`. `--list` 로 게시판에서 '합동감사 결과' 글 번호를 찾는다. mois.go.kr 은 이 세션에서 curl 로 받히지만 큰 파일은 연결이 자주 끊겨 다시 돌린다.

정리한 사례는 `data/vat/cases.yml` → `/vat/tools/#cases`. 공표 자료의 사실만 옮기고 평가하지 않는다. 개인 이름 없음(원문도 ㉮과·ⓐ 센터처럼 가림).
