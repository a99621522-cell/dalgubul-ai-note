# 감사원 감사결과 공개문 — 부가가치세 발췌

`scripts/fetch_bai_vat.py`(워크플로 `bai_vat.yml`, 매달 2일 + 수동)가 감사원 누리집 API(`/api/bak/dar/AWUBAKDAR001E` 목록·상세, `/api/files/download` 첨부 — 2026-11-03 확인, 스크립트 머리에 적음)로
감사 분야가 지방자치단체·지방재정·지방세이거나 제목에 지방공기업·공유재산·도시공사·공단이 든 공개문 PDF 를 받아 `부가가치세|매입세액|경정청구|세금계산서|과세사업|면세사업` 이 나온 문단(앞뒤 6줄, 700자)을
`<srno>.json`(제목·공개일·분야·감사 종류·누리집 링크·파일 이름·발췌 목록: 쪽·낱말·가까운 지적 제목·글)에 남긴다. 원문 PDF 는 저장하지 않는다. `index.json` 은 받은 보고서마다 상태(done / hwp = PDF 가 없는 배포용 한글·CSD 라 못 읽음 / nofile / fail)와 문단 수.

- 2016년 이전 공개문은 대부분 배포용 HWP(.hwp 또는 .csd)라 글자를 뽑지 못한다 — 2010 「지방재정 운용실태」(srno 1005, 공유재산 사용료 부가세 예수금 지적)도 그렇다(cases.yml 에는 2차 자료 요지로, verify)
- 일부 PDF(폴라리스 뷰어로 만든 2017 지방공기업 Ⅱ)는 글꼴이 깨져 pdftotext 가 글자를 못 읽는다
- 사이트: `/vat/tools/#cases` '감사원 감사보고서' 표와 `/vat/review/` 사례 묶음. 발췌 그대로, 평가 없음. 공개문은 이미 이름을 가렸고 전화번호 꼴은 지운다
- 감사원 전문 검색(Konan `/api/konans/findBai`)은 공고 게시판만 찾아 보고서 본문 검색에는 쓸 수 없다(2026-11-03)
