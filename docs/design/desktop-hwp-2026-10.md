# 데스크톱·한글(HWP) 업무 흐름 — 1차 구현 기록 (2026-10-06)

프롬프트 `docs/prompts/site_desktop_hwp_ui.md` 를 순서(클립보드 페이로드 → 복사 묶음·캡션 → 그래프 저장 → 데이터 그리드 → 데스크톱 폭 → 붙임 꾸러미(docx) → HWPX 시험)대로 실행한 1차 기록. 서버·AI 호출 없음, 평가·순위 없음, 개인정보 열 없음(표에 애초에 없음).

## 2. 구현한 것

### 클립보드 페이로드(`src/scripts/table_tools.ts`)
- `text/html`: `<table border=1 cellspacing=0 cellpadding=3 style="border-collapse:collapse;border:0.5pt solid #000;font-family:'맑은 고딕';font-size:10pt;width:100%">` + `<colgroup><col style="width:n%">`(화면 열 폭 비율) + `rowspan`/`colspan` 보존 + `th` 음영 + 숫자 셀 `text-align:right;white-space:nowrap`. 인라인 스타일만.
- `text/plain`: TSV(병합 칸은 같은 값으로 채운 격자) — 엑셀·메모용.
- `text/rtf` 는 넣지 않음(브라우저 Clipboard API 가 RTF 쓰기를 막음 — 한글이 RTF 를 더 잘 읽는지는 운영자 시험 항목).
- 숨긴 열(`.col-off`)·행 체크 열(`.grid-sel`)·거른 행(`hidden`)은 복사·CSV·PDF·개조식에서 모두 빠진다.
- LibreOffice 로 `text/html` 을 열어 확인(2026-10-06): 두 줄 머리·rowspan·열 폭·음영 보존, 26열 표는 A4 세로에서 글자가 세로로 깨짐(열 선택으로 줄여 붙이는 것이 전제). 한글 2020/2022/2024 실물 시험은 `hwpx-compat.md` 의 표를 운영자가 채운다.

### 복사 묶음(모든 `table.data-table` 아래)
「한글 표 복사 ▾」(`details` 메뉴, Esc·바깥 클릭 닫힘): 표만 복사 / 제목·출처 줄 포함 / 머리 없이(값만) / 선택 행만 / 개조식 요약 문장(처음 8행 × 10열, 값을 그대로 옮긴 문장, 평가 없음) + 한글 마무리 3단계 안내 줄. 「CSV」(UTF-8 BOM, 두 줄 머리는 '매출액(억 원) 2023' 한 줄로 합침). 「PDF 내려받기」(열 8개 이상이면 가로). 결과는 토스트(`#tt-toast`, `role=status`).
「표 여러 개 한 번에」는 미구현(다음 단계).

### 그래프 도구(`src/scripts/chart_tools.ts`, `figure.chart`·`figure.tcard`)
PNG 저장(2배, 흰 바탕, CSS 변수 색을 계산값으로 박음) / SVG 저장 / 그래프 복사(ClipboardItem image/png) / 캡션 복사('그림. 제목 — 자료: daitda.co.kr/… (받은 날)'). 3배·'표로 보기'는 미구현(표는 그래프 아래 펼침에 이미 있음).

### 데이터 그리드(`src/scripts/grid.ts`, opt-in `table.data-table[data-grid]`)
적용: `/listed/` 재무·직원·연구개발비·미래 산업 공시 표, 통계 주제 페이지의 KOSIS 표(`KosisSections.astro`).
- 머리 고정: 표를 `max-height: min(70vh, 720px)` 상자(`.grid-scroll`)에 넣고 `thead th` sticky(두 줄 머리는 첫 줄 높이를 `--grid-h1` 로 재서 둘째 줄도 고정), 첫 열(행 체크 + 이름) sticky left.
- 정렬: 열 머리 클릭·Enter(오름 → 내림 → 해제), Shift 다중(번호 배지), `aria-sort`. 숫자는 수로, 글자는 `localeCompare('ko')`. 묶음 머리(colspan)는 정렬 안 함. 화면 라벨에 '순위'·'TOP' 없음('사용자 작업, 순위 아님' 안내 줄).
- 열 선택기(`details.grid-menu`, 체크 목록 + 모두 보이기), 표 안 검색(`/` 로 포커스, 일치 행 수), 행 체크(`aria-selected`), 밀도 토글(촘촘히/넓게, `aria-pressed`).
- 미구현: 열 폭 끌기, URL 인자(`?cols=`·정렬) 공유, 단위 환산·소수 자릿수·음수 표기 토글, 셀 하나 복사, 합계 행 sticky, 머리 셀 툴팁, 화살표 셀 이동·`?` 안내. 다음 단계.

### 데스크톱 폭(`Base` `wide` prop → `main.wrap.wide`)
1440px 이상에서 본문 1280px(표 페이지만: `/listed/`, `/stats/*`, `/stats/<월>`). 사이드 레일(목차·필터) 2단 배치는 미구현.

### 붙임 꾸러미 — Word(`src/scripts/company_docx.ts`, 기업 페이지 「기업 카드 Word」)
`docx` 패키지를 브라우저에서 동적 import(누를 때만 약 400KB 받음)해 pdf 판과 같은 Block 자료로 .docx(맑은 고딕 10pt, 표 0.5pt·머리 음영, 숫자 오른쪽). LibreOffice 변환으로 한 쪽 확인. 한글에서 '워드 문서 열기' 실물 시험은 운영자 항목. HWPX 는 시험 통과 전까지 내지 않는다.

## 3. 수용 기준 확인(2026-10-06, Playwright + LibreOffice)

| 기준 | 결과 |
|---|---|
| ① 한글 붙여넣기 6항목 보존 | LibreOffice 기준 테두리·병합·글꼴·정렬·열 폭·줄바꿈 보존. 한글 실물은 미시험(`hwpx-compat.md`) |
| ② 과업 클릭 수 50% 감소 | ①·④ 과업 5~6 → 2~3(1절 표) |
| ③ 1440px 에서 25열 표 | 본문 1280px + 머리·첫 열 고정 + 열 선택으로 읽힘(가로 스크롤은 상자 안) |
| ④ 키보드만으로 정렬·열 선택·복사 | 머리 Enter 정렬, `details` 메뉴 Tab/Enter, `/` 검색 — 확인 |
| ⑤ axe 0·접근성 100·CLS | CI `ui_audit.yml` 이 푸시마다 확인(CLS 는 표 도구 자리 선점 미적용, 다음 단계) |
| ⑥ 출처·기준일 포함, 개인정보 열 0 | 제목·출처 줄/캡션/CSV 는 없음(파일 자체)·PDF·docx 모두 URL·받은 날 포함. 개인정보 열은 표에 없음 |

측정 스크립트(세션 임시): 클립보드 `text/html`·`text/plain` 읽기(권한 `clipboard-read`), 정렬 `aria-sort` 전이, 열 숨김 55칸, 검색 1행 일치, 선택 행 2 → 복사 HTML `<tr>` 4개(머리 2 + 행 2), 개조식 문장, CSV·PNG·SVG·docx 내려받기, 1280px 에서는 1080px 유지·가로 스크롤 없음. headless 크로미움은 blob 내려받기 이름을 'download' 로 보고하지만 실제 브라우저에서는 `download` 속성 이름이 쓰인다(기존 PDF 단추와 같음).

## 4. 하지 않을 것
순위·TOP 라벨, 서버 처리·AI 호출, 개인정보 열, 평가·해석 문장 생성(개조식 문장은 값 옮김만), 대구시 예산액, HWPX(시험 통과 전).
