## 1. 요약(Executive summary)

| # | 결론 | 심각도 |

## 4. 디자인 참조 분석 — 한국은행 누리집 간행물 상세(운영자 제시 화면)

운영자가 보여 준 화면(지역경제보고서 2026년 7월 상세)을 **패턴 단위**로 해부하고 다잇다에 옮길지 판정한다. 로고·기관 상징·고유 색은 쓰지 않는다(기관 사칭 오해 방지, 1단계 제약).

| 영역 | 참조 화면의 패턴 | 다잇다 현재 | 판정 |
|---|---|---|---|
| ① 유틸리티 바 | 맨 위 작은 글씨 링크 줄(경제연구원·ECOS·전자도서관 등) + 오른쪽 '본인인증·ENGLISH' | 없음 | **도입** — 출처 기관 바로가기(KOSIS·DART·공공데이터포털·지방재정365), 사이트 소개 |
| ② 글로벌 내비게이션(GNB) | 로고 왼쪽, 큰 글씨(약 24px) 대메뉴 5개를 가운데 넓게, 선택 메뉴 밑줄, 오른쪽 전체 메뉴(☰)·검색 원형 단추 | 15px대 메뉴 4묶음 + 돋보기, 오른쪽 정렬 | **도입** — 대메뉴 글자 키움·가운데 배치·전체 메뉴(사이트맵 패널) 단추 |
| ③ 위치 표시(Breadcrumb) | 'Home › 뉴스/자료 ⌄ › 간행물 ⌄ › 지역경제보고서 ⌄' — 단계마다 **드롭다운으로 형제 메뉴 이동** | 글자 링크 브레드크럼(단계 이동만) | **도입** — 드롭다운 브레드크럼(형제 페이지 빠른 이동) |
| ④ 페이지 머리 띠(Title band) | 옅은 청색 면(surface tint) 위: 위 작은 분류명 → 큰 제목 → 오른쪽 메타(분류·날짜·조회수) → 아래 태그 칩 → 오른쪽 아래 담당 부서 | 흰 바탕 제목 + 한 줄 메타 | **도입** — 다잇다 '페이지 머리' 표준: 분류(메뉴 묶음) · 제목 · 메타(기준일·출처·갱신 주기) · 태그(주제 칩, 누르면 관련 목록) · 담당 표시 대신 '자료 출처 기관'. 조회수는 넣지 않음(인기·순위 신호) |
| ⑤ 페이지 행동 | 띠 오른쪽 위 아이콘 3개(공유·인쇄·RSS) | 페이지마다 다른 큰 버튼 | **도입** — 공유(링크 복사)·인쇄·내려받기 아이콘 + 글자 라벨(아이콘 단독 금지 원칙) |
| ⑥ 첨부 파일 목록 | 굵은 위선 아래 파일명 목록, 오른쪽에 '다운로드 \| 뷰어' 짝, 접기 단추 | 줄글 링크 | **도입** — 리포트·기업 카드·표 내려받기를 같은 '첨부 목록' 컴포넌트로(형식·크기·쪽수 표시) |
| ⑦ 문서 뷰어 | 첨부 아래 PDF 뷰어(쪽 이동·확대·인쇄) | 없음 | **검토** — 브라우저 내장 PDF 뷰어(`<iframe>`/`<object>`)로 지연 로드. 모바일은 내려받기 우선 |
| ⑧ 시각 언어 | 넓은 여백, 큰 제목(약 36px), 가는 선, 면 색으로 구역 구분, 그림자 거의 없음 | 대체로 같은 방향 | **유지·강화** — 면 색(옅은 청색 tint) 1종 추가, 제목 크기 상향 |
| ⑨ 장식 그래픽 | 머리 띠 오른쪽 입체 도형 일러스트 | 없음 | **도입 안 함** — 공공 신뢰 톤·데이터 우선 원칙(장식 금지) |
| ⑩ 담당 부서·전화 | 머리 띠 아래 담당팀·전화번호 | 없음 | **도입 안 함** — 개인 운영 사이트이며 개인정보·기관 입장 오해 소지. 대신 '문의' 한 곳 |

**참조를 적용할 대상 페이지 유형**: 리포트 상세(신설)·리포트 목록, 통계 주제 페이지, 상장기업·기업 상세, 지원 기업. 데이터 그리드·계산기는 머리 띠만 공유하고 본문은 다잇다 고유 패턴 유지.
