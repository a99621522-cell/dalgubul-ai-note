## 3. 디자인 토큰 v3 (`src/styles/tokens.css` 끝 절)

- **3계층**: 원시 램프(`--blue-50…900`, `--gray-50…900`) → 의미(`--color-surface-0/1/band`, `--color-line-band`, `--color-link*`) → 컴포넌트(`--band`, `--band-line` 등). 기존 이름(`--primary`·`--surface`·`--line`)은 그대로 두어 페이지 코드는 바뀌지 않는다.
- **주색 램프**: 기존 `--primary #1B4F9B` 를 600 단계로 두고 같은 색상각에서 명도만 바꿈. 띠 면 = 100(`#eaf1fa`), 띠 선 = 200.
- **타입 스케일**: 기본 18px, 비율 약 1.2, 제목은 `clamp()` 유동 — `--fs-display`(첫 화면 제목)·`--fs-h1`(페이지 제목 띠)·`--fs-h2`(절 제목)·`--fs-h3`.
- **모서리**: 4px(표·작은 단추)·8px(`--radius-2`, 카드·검색창) 두 단계만.
- **그라데이션 없음**: 첫 화면 제목·검색 단추의 그라데이션을 단색으로(공공 신뢰 톤).
- 데이터 색(`--chart-*`, Okabe–Ito)과 상태색(`--status-*`, 시스템 메시지 전용)은 바꾸지 않음.

| 순서 | 블록 | 이유(감사 근거) |

| 3 | 게시판 2칸: 리포트(최근 5건) · 자료 갱신 현황(자료마다 기준 시점) | H2: '무엇이 언제 기준인가' 신호, H3: 회전 카드 제목이 접힘선 아래 → 목록 |
| 4~ | 큰 숫자 4개 → 산업단지·특구별 → 산업별 → 고용 추이 → 최신 글 | 기존 유지 |

## 5. 검색 표시 순서

- 글·사업 색인(약 90KB)을 먼저 받아 그리고, 기업 색인(약 2.9MB)은 도착하는 대로 채운다. 기업 목록 자리는 미리 잡아(24rem) 아래 목록이 밀리지 않게 한다.
- 남은 과제: 기업 색인 자체를 줄이는 것(필드 축약·분할 색인) — 3단계.
