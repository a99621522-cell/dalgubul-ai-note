# 지자체 부가가치세 최소화 — 설계 (2026-11-05)

프롬프트: `docs/prompts/vat_minimize_upgrade.md`(운영자 '그 프롬프트로 진행해'). 첫 대상은 달성군이고, 달성군 검증이 끝나야 수성구로 넘어간다. 규칙·계산(`rules.yml`, `judge`)은 조문 대조 없이 바꾸지 않는다.

## 1. 공무원 행동 — 목표

| 단계 | 행동 | 지금(세 걸음 판) | 목표 |
|---|---|---|---|
| 기관 | 고르기 | 2(선택·단추) | 2 |
| 자료 | 홈택스 파일 놓기 | 2칸(②·③ 따로) | **1칸**(`#rf-all`, 섞어 놓기) |
| 시설 귀속 | 공급자마다 시설 고르기 | 못 붙은 공급자 수만큼 | **질문 ≤10**(돈 큰 순, 예/아니오/모름) |
| 결과 | 묶음 내려받기 | 1 | 1 + 홈택스 입력값표 |

## 2. 대조 관문 (금액을 보여 주기 전에)

과세기간마다 올린 파일이 그 기관 신고와 맞는지 먼저 본다(`vat_diag.ts gate`).

| 대조 | 식 | 결과 |
|---|---|---|
| 세금계산서 | 매입 목록(세금계산서) 세액 합 ↔ 신고서 (10)+(12)(+(13)) | 같음 / 목록이 많음(신고에서 빠짐 후보) / 신고가 많음(목록이 덜 올라옴 — 다른 기간·종이 세금계산서) |
| 카드 | 카드 목록 세액 합 ↔ (15) 그 밖의 공제매입세액 | 같은 세 갈래 |
| 칸 계산 | (16) − (17) = (18) | 맞음 / 읽기 확인 |
| 불공제 명세 | 명세서 ①~⑧ + 안분 불공제 합 ↔ (17) | 맞음 / 명세서 확인 |

- 차이 1,000원 이하는 같다고 본다.
- '신고가 많음'이면 그 기간 금액을 **잠정**으로 표시하고, 할 일 맨 위에 '그 기간 매입 목록을 다시 받으세요'를 둔다.
- 대조표는 진단 카드 맨 위에 둔다.

## 3. 질문 엔진

사실 공백을 질문으로 바꾸고, 답하면 그 자리에서 판정과 금액을 다시 계산한다(`src/scripts/vat_ask.ts`).

- **질문의 출처**
  - ① 예시 설정 시설의 `ask:`(조사로 남은 확인 사항 — 문항·예/아니오일 때 바뀌는 유형·운영 방식·메모, 근거)
  - ② 운영 방식이 '확인 필요'이고 걸린 돈이 큰 시설(직영 / 공단·수탁기관이 군 명의로 대행 / 수탁기관 자기 사업)
  - ③ 매출 쪽 과다 납부(면세인데 과세로 신고했는지) — 4절
- **걸린 금액**
  - 그 시설에 붙은 매입 목록 세액. 목록이 없으면 경정청구 기간 계약 세액 어림(회색)과 세입예산서 수입(매출 쪽).
  - 예/아니오로 갈리는 금액만 센다.
- **보여 주기**
  - 걸린 금액 큰 순으로 한 번에 하나만 보인다. 나머지는 「다음」, 전체는 펼침에서 본다.
  - 최대 10개다. 그 밖은 '나중에'로 접는다.
- **답 저장·재계산**
  - 답은 `org.facilities[].answers[id]` 에 남긴다(인수인계 zip 에도 들어감).
  - 답의 패치(유형·운영 방식·메모 덧붙임)를 시설에 적용하고 `vat-org-v1` 저장 → 세 걸음 판 다시 그림.
  - '모름'은 판정을 바꾸지 않고 '판단 필요'로 남긴다.
- 질문 문장은 현장 말로 쓰고, 옆에 '이 답에 걸린 금액'과 근거(조문·유권해석)를 한 줄로 단다.

## 4. 매출 쪽 과다 납부와 순효과

- 면세 유형 시설(주차·체육공원 운동시설·농기계 임대 등)의 세입예산서 수입이 있으면 질문한다: '이 수입을 부가세 과세 매출로 신고해 왔나요?'
- **예**면 과다 납부한 매출세액 어림(연간 수입 × 10/110 × 경정청구 기간의 해 수)과, 그 시설 매입세액을 공제받아 왔다면 그 불공제 전환분을 함께 보여 순효과를 낸다.
  - 판정은 법대로 하고, 순효과는 결과로만 보인다.
  - 매출 명세(신고서 과세표준 명세 (31)~(35))로 확정한다.
- 어림이라 '판단 필요' 칸에 둔다.

## 5. 경정청구 화면 입력값표

과세기간마다 홈택스 「신고/납부 → 세금신고 → 부가가치세 → 경정청구」 화면 순서로 적는다.

1. 과세기간·신고 구분(확정)·경정청구 사유(초안 한 줄)
2. 매입세액 칸 — 당초 / 경정 후 / 차이: (10) 일반매입, (12) 고정자산매입, (16) 합계, (17) 공제받지 못할 매입세액, (18) 차감계
3. 납부(환급)세액 — 당초 / 경정 후 / 돌려받을 세액
4. 붙임: 매입처별 세금계산서합계표 추가분(공급자별)·공제받지못할매입세액명세서(고친 안분)·사유서·근거(조문·유권해석)·진단표

- 각 숫자 옆에 출처 사슬을 붙인다: 「파일명 → 행 수 → 시설 → 판정 → 조문」.
- 진단 카드·엑셀 시트 `홈택스 입력값`·PDF 에 같은 내용을 넣는다.

## 6. 수용 기준

- 달성군 시나리오(예시 설정 + 고정 홈택스 파일 + 질문 답)에서 다음을 확인한다.
  - 공무원 행동 = 기관 2 + 파일 1 + 질문 ≤10 + 내려받기 1
  - 대조표가 과세기간마다 있음
  - 질문에 답하면 금액이 즉시 바뀜(식으로 견줌)
  - 입력값표 (18) 경정 후 = 당초 + 돌려받을 세액
  - 출처 사슬 열이 비지 않음
- 기존 수용 시험 138개 유지.
