# 지난 돈 돌려받기 — 세 걸음 판 (2026-11-05)

프롬프트: `docs/prompts/vat_refund_3steps.md` (운영자 '그 프롬프트로 진행해'). 규칙·계산(`rules.yml`, `judge`, `unlockCompute`)은 그대로이고 화면과 흐름만 바꿨다.

## 1. 조사 — 바꾸기 전(before)

달성군 예시, 1280×800, 고정 자료(`filed_2024_2.txt`, `invoice_list.xlsx`)로 직접 해 본 값(Playwright).

| 첫 화면 글자 수 | 13,749 | 2,073 |
| 첫 화면 보이는 입력·단추 | 25 | 28 |
| 첫 금액까지 행동(기관·신고서·매입 목록) | 5 (목록에 더하기 별도) | 4 (기관 고르기 2 + 신고서 1 + 파일 1) |

## 2. 설계

- **세 걸음**(`ol.rf-steps`): ① 기관 고르기 ② 지난 신고서 올리기 ③ 홈택스 매입 목록 올리기. 걸음마다 상태(완료 ✓ / 지금 할 걸음 굵은 테두리) 한 줄.
- **금액 띠**(`#rf-band`, 위에 붙음): '지금까지 찾은 돌려받을 수 있는 금액' = 확정 + 자료를 더 내면(`unlockCompute` now + docs). 작은 글씨로 확정·자료·판단 필요·시설 정하기 전. 나라장터 계약 세액 추정은 회색 작은 글씨 '돌려받을 금액이 아닙니다'.
- **① 기관**: 기관을 고르면(빠른 시작) 공개 자료를 붙였다고 알리고(나라장터 계약 수 · 과세 시설에 붙은 계약 · 공제 가능성 있는 유형), 경정청구 기한 막대(120일 안 ⚠).
- **② 신고서**: PDF 여러 개를 한꺼번에. 읽은 뒤 과세기간별 표 '신고한 매입세액 (18) | 계약 세액 추정(참고) | 큰 계약 | 기한 | 표시' — 계약 쪽이 크면 '먼저 볼 기간', 신고 없음이면 '기한후신고 후보', 그리고 **'홈택스에서 받을 기간'** 한 줄(5년 20번 조회를 줄임). 견줌은 순서일 뿐 증거가 아니라고 한 줄.
- **③ 매입 목록**: 파일 여러 개 한꺼번에, 머리글에서 날짜·세액(또는 합계)·공급자 열이 다 잡히면 '목록에 더하기' 없이 바로(되돌리기 토스트), 못 잡은 파일만 열 맞추기. 시설은 ⓐ 나라장터 계약 업체 사업자등록번호(그 업체의 시설이 붙은 계약이 모두 같은 시설일 때만, `vat_contracts.ts contractsCtx().biz`) ⓑ 매핑표 ⓒ 시설 이름 일치 순으로 저절로, 공급자 표는 **못 붙인 것만 · 세액 큰 순 10곳**(나머지 보기, 거르기 선택은 `vat-rv-supf` 에 기억). 붙여넣기·공개 지출 자료·JSON 은 '다른 방법' 펼침.
- **할 일**(`#rf-todo`): 한 줄에 하나 — 지금 청구할 금액, 자료별(무엇을 내면 +얼마), 판단 필요, 못 정한 공급자, 신고 값 없는 기간. 금액 큰 순 → 기한 급한 순, D-day 표시. 「경정청구 묶음 내려받기」·「할 일 인쇄」.
- **묶음**: 기존 zip + `10_경정청구_자료.xlsx`(과세기간별·건별·공급자별(합계표 추가분)·시설별·자료별·사유·근거 7시트, `xlsx_write.ts` 라이브러리 없음) + `11_경정청구_요약.pdf`(가로, `pdf.ts`). '엑셀만'·'PDF 만' 단추도.
- **자세히 보기**(`details#rf-more`): 기존 금액 카드·자료별 금액·② 신고 값 표·④ 결과·근거·사유 초안 그대로.

## 4. 남은 것

- 홈택스 합계표(공급자별 합계, 과세기간당 1파일)는 작성일자가 없어 아직 읽지 않는다 — 형식을 확인하면 ③에 더한다.
- 종이 세금계산서는 목록조회에 없다(2022-07 전 개인사업자 공급분이 많음) — 할 일에 안내를 더할지 법령 연혁 대조(`docs/design/vat-law-changes-2021.md`) 뒤 정한다.

## 5. 달성군 실제 계약으로 돌려 본 결과 (2026-11-05)

나라장터 계약 2020-07~2026-11 을 다 받은 뒤 달성군 예시(시설 68곳, 빠른 시작)로 ① 단계 계산(`contractsCtx`)을 그대로 돌렸다.

**처음 돌렸을 때 틀린 것과 고친 것**
- 같은 계약이 여러 줄: 변경계약마다 통합계약번호가 새로 붙어 '테크노 스포츠센터 건립공사(2차)' 한 건이 7줄 → 상세 주소의 원계약번호(ctrtNo)·변경 차수(ctrtChgOrd)로 마지막 변경 한 줄만(계약일은 처음 계약일). 25,319줄 → 12,176건. 수집(`fetch_g2b_contracts.py latest_by_contract`)과 사이트(`vatContracts.ts latestByContract`) 둘 다.
- 금액: 장기계속·계속비는 총계약금액이 차수 계약마다 되풀이 → 금차 계약금액 먼저(`ctrMoney = amt || tot`). 계약 금액 합 5조 3천억 → 9,791억 원.
- 도로·부지 공사: '파크골프장 진입도로 개설공사'·'임대주택단지간 도시계획도로'가 과세 시설 계약으로 셈 → 공사 갈래 짐작(`guessCw`)이 도로·토목이면 빼고 셈.
- 이름 일치: '군유재산 임대'가 '임대주택단지'·'정수기 임대'에 붙음 → '임대·임차·대여·구입'을 가름에 쓰지 않는 낱말로.
- 유형: '음식물류폐기물 수집운반'이 '물류'로 임대 시설이 됨 → `물류(센터|단지|시설|창고)`, '임대(?!주택)'; 면세 입장 문화시설·무료 공원은 `low`.

### 중구·동구 (같은 날, 수집이 끝난 두 곳)

- 세입예산서에서 불러온 시설 후보에 수입 항목 이름('도로'·'하천'·'공유재산' 사용료, '…수수료')과 임차인 이름('사회적협동조합 ○○')이 섞여, '도로'가 도로 공사 계약 457건에 붙어 과세 시설 계약으로 셈 → 이런 이름은 시설 이름 일치에 쓰지 않음(`vat_rules.ts noNameMatch`; 붙여넣기·공개 지출 자료에도 같이 적용).
- 고친 뒤 경정청구 기간(2021-2~2026-1):
  - 동구(계약 7,159건): 과세 시설에 붙은 계약 17건·세액 추정 0.5억 원(도동복합운동장 조성 등 체육시설), 공제 가능성 유형 214건·5.2억 원.
  - 중구(계약 2,716건): 중구 세입 자료가 총괄표뿐이라 시설 후보가 없어 붙은 계약 0건, 공제 가능성 유형 96건·28.3억 원(대부분 복지누리 반다비 체육센터 건립공사 2024-2).
- 두 곳 모두 기관 설정에서 실제 유료 시설을 적어 넣어야 계약이 시설에 붙는다 — 세입예산서 후보만으로는 시설 목록이 비어 있거나 수입 항목 위주다.
- 서구·남구·북구(2023-09까지)·수성구·달서구·군위군·본청은 하루 호출 한도에 걸려 2026-11-06 0시 뒤 이어 받는다.
