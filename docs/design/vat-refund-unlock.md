# 지난 신고서 → 자료 → 돌려받을 금액 (2026-11-04)

운영자 지시: '국세청 홈택스에 지난번 올린 것을 올리면 어떤 자료를 추가로 올리면 환급을 얼마 받을 수 있다는 시스템' → 프롬프트 `docs/prompts/vat_refund_unlock.md` → '그대로 실행해'.

## 2. 데이터 구조

- `FiledDoc`(`src/scripts/vat_unlock.ts`) — 파일 하나에서 읽은 신고서: `reg`·`year`·`half`·`kind`(예정/확정/기한후/조기환급/모름)·`from/to` 월·`cells{n: {amt, tax}}`(1~18, 53~56)·`nd`(22호: `reasons[1..9]`·`common{sup,tax,total,exempt,nd}`)·`file`·`warn[]`.
- `filedSummary(docs)` → 과세기간(확정 기준 `YYYY-1/2`)마다 (18)·(17) 합(예정+확정, 같은 구분이 두 번이면 뒤 파일이 앞 파일을 바꿈 — 수정신고), 면세비율(22호 Σ⑭÷Σ⑪, 없으면 ⑬÷⑫), 과세 매출 공급가액·세액((1)~(4) 합), 읽은 파일 이름.
- 기존 `st.filed[k]`(`vat-review-v1`)에 그대로 넣는다(신고 = '함 — 이 목록도 넣었음'). 새 필드: `st.filedDocs`(요약만, 원문 없음)·`st.docs{key: {name?, at}}`(올린 자료 표시)·`st.sales{k: 신고에 없던 과세 시설 매출 공급가액}`.

## 3. 엔진 — 후보·상태·필요 자료

건마다(기존 `judgeRow` 결과 `RowOut`) 잠재 세액과 상태를 정한다. 새 판정 규칙 없음.

| 판정(`cat`) | 잠재 세액 | 상태 | 필요한 것 |
|---|---|---|---|
| `ok`(과세 시설 전용) | 세액 | 시설 자료 묶음이 있으면 **지금 자료로 됨**, 없으면 **자료를 올리면 됨** | `fac:<시설>` — 지출 귀속 증빙(계약서·검수조서·사업명) + 과세 근거(사업자등록·매출 신고 사실) |
| `split`(여러 시설 공통) | 세액 × (1 − 면세비율) | 위와 같음 | `fac:<시설>` |
| `split` 본청·행정 공통 | 세액 × (1 − 면세비율) | **판단 필요** | 안분 기준(영 제81조 제4항 — 고유사무는 공급가액이 없음, admin_common 판례·질의서) |
| `noratio`(공통인데 면세비율 없음) | 세액(상한) | **자료를 올리면 됨** | `ratio:<과세기간>` — 그 기간 공급가액(22호 ⑫⑬) |
| `check` 시설 유형 '확인'(대관·광고 자리) | 세액 | **판단 필요** | 그 유형 기준 문장·유권해석·질의서 |
| `check` 시설 미지정 | 세액(상한) | **시설 정하기** | ③에서 시설 지정 |
| `other` 다른 명의 | 세액 | 수정세금계산서 기한 안이면 **자료를 올리면 됨**, 지났으면 셈하지 않음 | `fix:<공급자 등록번호>` — 수정세금계산서 |
| `no`·`none`·수탁·대행 | 0 | — | — |

과세기간마다 **신고한 공제 세액 (18)이 근거가 갖춰진 건부터 덮었다**고 보고(보수적) 남는 몫을 나눈다: 지금 자료로 = max(0, Σ지금 − (18)); 남은 (18)이 자료 필요 건을 덮고, 그다음 판단 필요 건을 덮는다(비례 배분). '이 목록은 안 넣었음'·'신고 안 함'이면 (18)을 0으로, '모름'이면 상한으로 표시.
자료별 '+얼마' = 그 자료(조합)가 풀어 주는 몫의 합 — 금액 순(평가 아님). 자료를 '있음'으로 바꾸면 그 건들이 '지금 자료로 됨'으로 옮겨진다.

## 4. 순액

- 과세 시설 지출을 공제받으면 그 시설의 매출도 신고돼 있어야 한다. 신고서에서 읽은 과세 매출 (1)~(4)가 0 이거나 사용자가 '신고에 없던 과세 시설 매출'을 넣으면 매출세액 10% + 과소신고(기한후면 무신고) 가산세·납부지연 가산세(`penaltyCalc`, 오늘 납부 가정)를 뺀다.
- 합계표 미제출분 가산세 0.5%(기존 `rv-net` 와 같은 식)를 뺀다.
- 경정청구 기한(법정신고기한 + 5년)이 지난 과세기간·아직 신고 전 과세기간은 금액에서 빼고 따로 보인다.

## 6. 수용 기준 (`scripts/vat_ux_test.mjs` U1~U5)

- U1 지어낸 신고서 텍스트 2건(2024년 제2기 확정, (18) 1,000,000·(17) 200,000·22호 ⑪ 300,000 ⑭ 90,000) → ② 표에 신고 '함', (18)·(17)·면세비율 30% 가 들어감.
- U2 매입 목록: 과세 시설 전용 3건(세액 1,500,000) → 시설 자료가 없으면 '자료를 올리면' = 1,500,000 − 1,000,000 = 500,000, 자료를 '있음'으로 하면 '지금 자료로' 500,000.
- U3 신고서 과세 매출이 0 이고 신고에 없던 매출 1,000,000 을 넣으면 순액이 매출세액 100,000 + 가산세만큼 줄어듦(식으로 대조).
- U4 기한이 지난 과세기간(2020년 제1기)은 세 칸에 들어가지 않고 '기한 지남'에만.
- U5 기존 시험 전부 통과.
