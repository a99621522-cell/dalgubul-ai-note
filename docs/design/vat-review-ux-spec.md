## 1. 화면 구조

```
[머리] 지자체 부가세 돌려받기
[제목 띠] 지난 부가세 돌려받기                     경정청구 · 지난 5년
  한 줄: 지난 5년 신고에서 덜 돌려받은 부가세를 찾아 얼마·왜·어떻게를 보여 줍니다. 파일은 이 브라우저 안에서만.
[문맥 바] 기관 · 시설 N곳 · 기관 바꾸기 | 저장 시각          (글자 크기는 오른쪽 작은 단추)

┌ 1  기관 고르기 ─────────────────────── 완료 ┐
│ [대구광역시 달성군 ▾] [이 기관으로 시작]      │   ← 고른 뒤: '대구광역시 달성군 — 시설 59곳' 한 줄 + 특성 펼침
└──────────────────────────────────────────┘
┌ 2  홈택스 파일 올리기 ──────────────────────┐
│ (잠김) 기관을 고르면 열립니다                  │
│ ┌ 파일을 여기에 끌어다 놓거나 [파일 고르기] ┐ │   ← 한국어 단추, 기본 input 숨김
│ └ 신고서 PDF · 매입 목록 엑셀 섞어도 됨 ──┘ │
│ 놓은 파일: 2021_2.txt [신고서·2021년 제2기] …│   ← 종류·과세기간 배지, 못 읽은 파일은 이유 + 어떻게
│ ▸ 어떤 파일을, 홈택스 어디서 받나요?          │
└──────────────────────────────────────────┘
┌ 3  결과 ──────────────────────────────────┐
│ 대구광역시 달성군은 경정청구로 약 460,000원을   │   ← 한 문장(역피라미드 맨 위)
│ 돌려받을 수 있습니다.                         │
│ 확정 460,000원 | 확인하면 최대 +5,200,000원     │   ← 금액 종류를 칸으로 가름, 참고 어림은 회색 접힘
│ 신고서 10장(9개 과세기간)으로 다시 계산 · 참고 계산이며 기관의 판단이 아닙니다 │
│ ─ 과세기간별 ─                               │
│ 2022년 제1기  함께 쓴 비용 나누기 계산 틀림   300,000원  D-1,7xx ▸왜·근거 │
│ …                                          │
│ ⚠ 2022년 제2기 신고서가 없습니다 — 올리면 더 찾을 수 있습니다 │
│ [세무서·홈택스에 낼 자료 받기(엑셀+PDF)] [결재용 보고 받기(Word)] │
│ ▸ 다른 형식(엑셀만·PDF 만·CSV)                │
│ 금액을 크게 바꾸는 확인 질문(3개까지)            │
└──────────────────────────────────────────┘
▸ 자세히 — 돌려받을 돈 표 전체 · 고친 신고서 · 지난 신고 진단 · 할 일
▸ 파일별로 보기·고치기 — 올린 신고서 · 매입 목록 · 공급자 시설 정하기 · 다른 방법
▸ 참고 — 가산세 계산기 · 다른 지자체 사례·감사 · 무엇을 보는 것인가
```

## 3. 문구표

| 지금 | 바꿀 말 |
|---|---|
| 지난 돈 돌려받기 — 세 걸음 | 지난 부가세 돌려받기 |
| 우리 기관이 지난 5년 동안 … (3줄) | 지난 5년 신고에서 덜 돌려받은 부가세를 찾아 얼마·왜·어떻게를 보여 줍니다. 파일은 이 브라우저 안에서만 읽습니다. |
| 지금까지 찾은 돌려받을 수 있는 금액 0 원 (파일 전) | (보이지 않음) — 결과 칸에 '파일을 올리면 여기에 금액이 나옵니다' |
| Choose Files / No file chosen | 파일 고르기 / 아직 고른 파일 없음 |
| 바로 돌려받을 돈 | 확정 — 신고서 숫자로 다시 계산 |

## 4. 상태표

| 상태 | 결과 칸 |
|---|---|
| 기관 없음 | 단계 2·3 잠김: '기관을 고르면 열립니다' |
| 파일 없음 | '홈택스에서 받은 신고서 PDF 를 2에 놓으면 여기에 금액이 나옵니다' |
| 읽는 중 | 파일 칸 아래 'n/N 파일 읽는 중…'(aria-live) |
| 일부 실패 | 파일 목록에 '못 읽음 — 이유 · 어떻게'(예: 스캔한 PDF 는 글자가 없어 못 읽습니다 — 홈택스에서 다시 출력해 PDF 로 저장) |
| 결과 있음 | 한 문장 + 금액 칸 + 기간 행 + 내려받기 둘 |
| 0원 | '찾은 것이 없습니다 — 이런 경우일 수 있습니다: ①…②…③…' + 매입 목록 올리기 안내 |
| 신고서 일부 | 결과 아래 '⚠ ○○ 신고서가 없습니다 — 올리면 더 찾을 수 있습니다' |
| 기한 지난 기간만 | '올린 신고서는 모두 경정청구 기한(5년)이 지났습니다' |

## 5. 수용 기준

프롬프트 5절 표 그대로(과업 A 클릭 4 이하·스크롤 0화면, 첫 화면 글자 절반 이하, 결과 첫 화면 낯선 용어 0, 강조 내려받기 2, 계산 값 그대로, axe 0, 390px 가로 스크롤 없음).
측정 정의: '결과 첫 화면'은 결과 요약 `#rf-sum` 안의 펼쳐 보이는 글자. '낯선 용어'는 괄호 칸 번호·원문자 칸·세법 낱말이 같은 줄에 쉬운 말 풀이 없이 나오는 것.
