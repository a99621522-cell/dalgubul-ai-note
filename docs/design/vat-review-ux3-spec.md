   [파일을 끌어다 놓거나 (파일 고르기)]  · 잠긴 엑셀은 엑셀에서 복사해 Ctrl+V

   ▸ 자세히 — 과세기간별 내용·확인 문단·후보·그 밖에 확인할 것(접힘)

## 문구표

| 자리 | 문구 |
|---|---|
| 강조 단추 | 고친 신고서 받기 |
| 단추 밑 작은 글 | PDF만 · Word만 · 엑셀만 · 세무서 제출 묶음(전체) |
| 진행 | 지출 30,000건 정리 중… / 신고서 20장 중 7장 읽는 중 |

## 상태별 화면
- 처음: ① 만 활성, ② ③ 은 '자료를 넣으면 여기에…' 한 줄.
- 자료 넣는 중: ① 아래 진행 막대와 글(붙여넣기·PDF 읽기 모두). 끝나면 ③ 으로 스크롤.
- 확인할 것 있음: ② 에 5개까지(금액 큰 순), 나머지는 접힘.
- 끝: ③ 한 문장 + 강조 단추 하나.

## 수용 기준(시험 R3-1~R3-5)
- R3-1 첫 화면: '먼저 볼 곳' 접힘, 강조 단추 1, 글자 ≤ 지금의 1/3(1,157자 이하, 1920)
- R3-2 붙여넣기: 0.5초 안에 진행 글이 보이고, 끝나면 사라짐
- R3-3 다시 열기: 다시 올릴 파일 0(신고서·지출 그대로)
- R3-4 확인할 것: 처음 보이는 질문 5개 이하
- R3-5 받기: 강조 단추 「고친 신고서 받기」 한 번 → zip 안에 PDF·docx·xlsx·안내, 받기 단추까지 읽을 글자 ≤ 지금의 1/3(725자 이하)
