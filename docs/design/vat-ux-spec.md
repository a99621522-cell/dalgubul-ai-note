# 지자체 부가세 절감 점검기 — 공무원 사용자 중심 UI/UX 설계 명세 (2026-10-28)

입력: `docs/prompts/vat_ux_civil_servant.md`(요구), `docs/design/vat-ux-research.md`(리서치·휴리스틱·before 측정). 불변 제약(정적 사이트·브라우저 안 계산·localStorage+파일·저장 키 호환·조문만·평가 없음·개인정보 없음·홈택스 흉내 없음·토큰 v3·프레임워크 없음·WCAG)은 그대로다. **법령 규칙·계산 로직은 한 줄도 바꾸지 않는다** — 같은 입력에 같은 결과가 나와야 하고, 달라지면 버그다.

## 1. 정보 구조(IA)

### 1.1 3단 메뉴(업무 주기 순)

| 1단(묶음) | 2단(화면) | 주소(변경 없음) | 언제 |
|---|---|---|---|
| 지금 할 일 | 대시보드 | `/vat/` | 늘 |
| 기록 | 지출 기록(붙여넣기·한 건) | `/vat/monthly/` | 매달 |
| 신고 | 신고 준비 | `/vat/prepare/` | 분기 |
| 신고 | 지난 신고 점검(경정청구·가산세) | `/vat/review/` | 처음·수시 |
| 신고 | 일정표 | `/vat/schedule/` | 수시 |
| 신고 | 납부액 추이 | `/vat/trend/` | 보고 때 |
| 설정·인수인계 | 기관 설정(시설 그리드) | `/vat/setup/` | 처음·시설 바뀔 때 |
| 설정·인수인계 | 과세사업 찾기 | `/vat/discover/` | 처음·해마다 |
| 설정·인수인계 | 인수인계 꾸러미 | `/vat/handover/` | 담당 바뀔 때 |
| 참고 | 한 건 판정·안분 계산기·질의서 | `/vat/tools/` | 아는 사람용 |
| 참고 | 신축·대수선 / 공영개발 | `/vat/build/`, `/vat/develop/` | 사업 있을 때 |

- 주소는 모두 유지하므로 넘김 페이지가 필요 없다. 기존 `/vat/` 의 「네 가지 길」「일하는 순서」 링크도 그대로 산다(progressive disclosure 안으로).
- 구현: `src/components/VatNav.astro` — 모든 `/vat/*` 페이지의 제목 아래 `<nav aria-label="부가세 점검기 메뉴">` 묶음 5개 × 화면 링크, 현재 화면 `aria-current="page"`. 768px 아래는 가로 스크롤 칩.

### 1.2 영속 문맥 바(persistent context bar)

모든 `/vat/*` 페이지의 메뉴 바로 아래 `<div id="vat-ctx" role="status">`: **기관 이름 · 등록 단위 · 시설 N곳 | 이번 기수(다음 신고 이름·D-day) | 마지막 저장 hh:mm(무엇을)**. 설정이 없으면 "기관 설정 없음 → 설정하기". 스크립트 `src/scripts/vat_ctx.ts`(Base 레이아웃을 건드리지 않고 VatNav 안에서 로드).

- 마지막 저장 시각은 새 키 `vat-saved-v1` = `{ org?: ISO, ledger?: ISO, filings?: ISO }` — `vat_rules.ts` 의 `setOrg/setLedger/setAllLedgers/saveFiling/setFilings` 가 쓴다. 기존 키·파일 형식은 그대로(호환). 인수인계 zip 에는 넣지 않는다(브라우저 상태일 뿐).

### 1.3 단계 표시줄(stepper)

- 기관 설정(5단계)·신고 준비(4단계)는 같은 컴포넌트 `.steps`(이미 있음)를 **단추**로 바꿔 `role="list"` + 각 단계 `<button aria-current="step">`: 끝난 단계는 클릭으로 되돌아감, 아직 안 간 단계는 `disabled`. 제목에 "N/5" 를 붙이고 `aria-live="polite"` 로 단계 바뀜을 읽는다.

### 1.4 용어 사전

`data/vat/rules.yml` 에 `glossary:` — `{ key, term(법령 용어), plain(현장 말), text(≤2문장), basis?: [{law, art}] }` 12개(실지귀속·공통매입세액·안분·면세비율·예정사용면적·간주임대료·예정신고/확정신고·예정고지·경정청구·수정세금계산서·사업자 단위 과세·공제받지 못할 매입세액·재계산). 화면은 `<button type="button" class="help" data-term="key" aria-expanded="false" aria-label="실지귀속 설명">?</button>` 하나로, `vat_rules.ts helpWire(root)` 가 단추 뒤에 `<span class="pop" role="note">` 를 넣고 뺀다(Esc·바깥 클릭·포커스 이탈로 닫힘). 문구 가이드 §6 의 '현장 말 — 법령 용어' 쌍을 이 사전에서 뽑아 쓴다.

## 3. 입력 UX

### 3.1 기관 설정 3단계 — 시설 그리드

```
3/5 시설마다 운영 방식·등록번호   필터: [전체 48] [검토 대기 31] [확인 필요 6] [번호 없음 40]
선택 행에 ▸ 운영 방식 [▾] 수탁·부서 [    ] 등록번호 [    ] [선택 행에 적용] [전체에 적용]
┌☐┬시설 이름──────┬유형────┬운영 방식──────┬수탁·부서──┬등록번호───┬수입─────┬상태──────┬ ┐
│☐│달성군민체육관  │체육 과세│[직접 운영  ▾]│          │555-83-…  │☑계☑카☐보│검토 대기 │▸│
│☐│달성문화회관    │공연 과세│[위탁 대행  ▾]│달성문화원│          │☑계☐카☐보│          │▸│
│ └ ▸ 펼침: 수탁기관 자기 사업일 때 받는 것 / 확인 결과·근거 / 출처 메모 / 같은 유형 하나 더·빼기 │
```

- `table.data-table.vat-grid`(`data-stack="off"`, `.scroll-x`, 첫 열 sticky 는 기존 표 규칙). 행 = `tr[data-fid]`, 칸의 입력은 기존 `[data-k]`·`[data-inc]` 그대로라 `read3()` 저장 로직은 유지. 펼침 행 `tr.sub[hidden]`(fee·decision·note·복제·삭제)은 `button[aria-expanded]` 로 연다.
- **검토 대기**: `run === 'unknown'` 인 행(예시·세입에서 불러온 것)은 `.verdict.check` 배지 '검토 대기' + 행 `data-pending`. 운영 방식을 고르면 배지가 사라진다. 필터 칩 '검토 대기' 가 기본 선택(불러온 직후), 직접 고른 시설만 있으면 '전체'.
- **일괄 적용**: 머리 위 도구줄. 행 체크박스(`th` 전체 선택 포함) → 「선택 행에 적용」, 또는 「전체에 적용」(필터된 행만). 적용 뒤 `role=status` 에 "N행에 운영 방식 '직접 운영' 적용 · 되돌리기".
- **smart default**: 새 시설의 수입 종류를 유형별 기본값으로(`DEFAULT_INCOME`: 임대·사용허가 → 세금계산서+보증금, 주차·체육·프로그램·매점 → 카드, 그 밖 → 카드). 운영 방식 기본은 직접 입력 시설만 `direct`(지금과 같음), 불러온 시설은 `unknown` 유지.
- 되돌리기: 「처음부터 다시」·예시 덮어쓰기·세입 불러오기 전에 `vat-org-backup-v1` 에 직전 org 를 두고 토스트 '되돌리기'(10초). confirm 은 `<dialog>` 로.
- 목표: 48곳 기준 노출 입력 필드 ≤ 60(펼침 닫힘 상태, 행마다 select 1·input 2·checkbox 3 = 6 × 10행 가시 … 전체는 288이지만 **필터 '검토 대기'·펼침 닫힘**으로 화면당 10행 안팎), 클릭 ≤ 20(일괄 적용).

- **열 머리 교정**: 미리보기 표의 첫 `thead` 행이 "원본 열" 행 — 대상(날짜·내용·공급가액·세액·합계·공급받는자 등록번호·공급자·공급자 등록번호·사업명·부서)마다 `select[data-col]`(현재 `#mb-map` 의 것을 옮김). 바꾸면 즉시 다시 그린다(단추 없음).
- **자동 귀속 뒤 미확정만**: `matchMap` 적중 행은 '자동' 묶음으로 접고, 기본 보기는 '미확정만'. 묶음 요약 줄에 건수·시설 분포. '전체' 로 열면 자동 행도 고칠 수 있다.
- **일괄 지정**: 행 체크 → 도구줄 select 4개 → 「적용」. 체크박스 머리 = 전체(보이는 행) 선택.
- **즉시 신호등**: 행마다 마지막 칸에 `judge()` 결과(`.sig` 아이콘 + 라벨) — 선택을 바꾸면 그 행만 다시 판정. 계산은 넣을 때와 같은 `toInput→judge` 라 결과가 같다.
- **인라인 검증**(제출 때 alert 없음): 금액·세액 모두 0 → 행 '금액 없음' 배지 + 체크 해제; 날짜 못 읽음 → '날짜 확인'(달 1일로 대체함을 표시); 같은 달 기록에 날짜·공급가액·세액·공급자가 같은 행 → '중복 가능' 배지 + 체크 해제. 요약 줄 `role=status`.
- **키보드**: 표 안 `↑↓` 로 같은 열의 위·아래 칸 포커스 이동, `Space` 로 행 체크 토글(체크 칸에서), `Ctrl+Enter` = 넣기. `vat_rules.ts gridKeys(table)`.
- **되돌리기**: 넣기·삭제·이 달 지우기는 `pushUndo()` — 토스트 `#vat-toast`(role=status) 10초, 명령 스택은 세션 안 최대 20개(`Ctrl+Z` 는 입력 상자 밖에서만).
- **자동 저장 표시**: 넣기·처리·삭제 뒤 문맥 바 '저장 hh:mm'.
- 한 건 넣기 폼도 `alert/confirm` 없음: 결과 카드(`#m-result`, 이미 `aria-live`) 유지, 지우기는 `<dialog>` 확인.
- 깊은 링크: `/vat/monthly/?fac=<id>&month=YYYY-MM&open=1`(대시보드·신고 준비 '지금 고치기' 가 씀) → 시설·달 선택·기록 표로 스크롤·`open=1` 이면 붙여넣기 펼침.

## 5. 접근성·키보드·인쇄

- 스킵 링크: Base 에 있음(`a.skip` → `#main`). `/vat/*` 는 추가로 `#vat-main-start`(메뉴 뒤 첫 제목) 로 두 번째 스킵 "메뉴 건너뛰기".
- 단계 단축키: 위저드 화면에서 `Alt+→`/`Alt+←` 다음·이전 단계(입력 상자 안에서도 안전).
- ARIA: stepper `role=list`/`aria-current=step`, 탭 `role=tablist/tab/tabpanel` + `aria-selected`·방향키, 그리드 표는 일반 `table`(ARIA grid 아님) + 키보드 이동만, 팝오버 `aria-expanded`, 토스트·요약·판정 결과 `role=status`(`aria-live=polite`), 처리할 것 카드 `aria-live=polite`.
- 신호등: `.sig` 는 색 + **모양**(초록 ●, 파랑 ◆, 빨강 ■, 노랑 ▲, 회색 ○ — CSS `clip-path`/문자) + 글자 라벨. 색각 시뮬레이션(Playwright 로 `deuteranopia` 필터 캔버스 대신 `forced-colors` 에뮬레이션으로 모양만 남는지 확인).
- 대비: 기존 verdict 색은 4.5:1 이상(확인값 기록 §8), 포커스 `--focus` 3px.
- 인쇄: `@media print` 를 `vat.css` 한 곳으로 — A4 여백 12mm, 머리글(기관·기간·만든 날, `body::before` 가 `data-print-head` 를 읽음), `thead { display: table-header-group }`, `.help/.btn/.vat-nav/#vat-ctx` 숨김, 탭은 전부 펼침, 페이지 번호는 브라우저 기본.
- 글자 크기 토글: 문맥 바 끝 「가 −/+」(3단계, `html[data-fs]` → `--text-base` 18/20/22px, localStorage `vat-fs`). 전역 토큰을 건드리지 않고 `/vat/*` 에서만.
- `prefers-reduced-motion`: 전역 규칙이 있음(transition·animation 끔). 토스트·스크롤 `behavior: smooth` 는 `matchMedia` 로 끈다.

## 6. 피드백·도움말·문구 가이드

- 빈 상태: 화면마다 한 문장 + 단추 하나(`.empty`에 `a.btn`). 예: 지출 기록 "기관 설정이 없습니다 → 기관 설정 5분".
- 첫 사용 안내: 모달 투어 없음. 화면 위 `.callout.info` 한 줄(닫기 가능, localStorage `vat-seen-<화면>`).
- `?` 도움말 = 용어 사전 팝오버(§1.4). 긴 설명은 `details`.
- 긴 작업(붙여넣기 500행 미리보기, 숫자표): `role=progressbar` 대신 "읽는 중… N행" `role=status`(동기 처리지만 50ms 넘으면 표시).
- **문구 가이드**(모든 새 문구에 적용):
  1. 한 문장에 한 가지. 동사로 끝낸다("고르세요", "넣으세요"). 명사 나열 금지.
  2. 현장 말 먼저, 괄호에 법령 용어: "이 시설만 쓴 지출(실지귀속)", "과세·면세에 함께 쓴 지출(공통매입세액)", "면세 비율(면세공급가액 ÷ 총공급가액)".
  3. 판정 결과 머리 문장은 고정: "판정은 참고이며 기관의 판단이 아닙니다." — 결과 화면(한 건 판정·미리보기·이 달 기록·신고서 결과·지난 신고 점검) 맨 위.
  4. 금지: 최적·추천·절세·유리·불리·절약 팁. 허용: 공제·불공제·줄어듭니다·돌아옵니다(조문 결과 서술).
  5. 조문은 "법 제39조 제1항 제7호" 꼴, 링크는 law.go.kr.
  6. 숫자: 원 단위 쉼표, %는 소수 둘째 자리까지, D-day 는 "D-12"(지났으면 "12일 지남").
  7. 단추: 동사+목적어 ≤ 8자("기록에 넣기", "숫자표 만들기"). 1차 단추 화면당 하나(`.btn`), 나머지 `.btn.secondary`/`.link-btn`.
  8. 사람·전화·개별 기관 금액 없음. 예시 값은 "가상" 또는 "예: 1,500,000".
