## 3. 내용 점검 — 수준 네 가지

| 수준 | 기준 |
|---|---|
| **위반 소지** | 다음 중 하나: ① 대법원이 무효로 본 판결과 같은 쟁점 ② 법제처가 '조례로 정할 수 없다'·'위배'로 회신한 의견과 같은 쟁점 ③ 상위법령 숫자·범위·권한과 직접 어긋남(예: 시행령 상한을 넘는 요율) ④ 주민 의무·권리 제한인데 법률 위임이 필요하고, 관련 법령 전문에서 위임 조문이 없음을 확인함 |
| **정비 권고** | 상위법령과 직접 어긋나지는 않지만 고쳐야 할 근거가 있는 것: 근거 조항이 다른 법으로 옮겨감, 법제처 '바람직하지 않다' 취지, 규칙에 맡기면서 조례에 대강(상한·산정 기준)이 부족함, 다른 기관(경찰·교육청)에 의무를 지움, 시 조례와 비율이 다름, 법률이 의무로 맡긴 조례 사항이 없음 |
| **규제 개선 권고** | 행정안전부 자치법규 규제 정비 기준에 해당: 행정정보 공동이용으로 확인 가능한 서류 요구, 인감증명서만 정하고 본인서명사실확인서를 빠뜨림, 법령에 없는 증명서 발급일 제한 |
| **참고** (사이트 숨김) | 위임 조문을 확인했거나(정비 대상 아님), 법령에 자격 제한이 없는 위원회에 의원을 '위촉할 수 있는' 사람으로 둔 것처럼 사안마다 판단이 갈리는 것 |

## 4. 상위법령 위임 대조 (참고 후보를 다시 가를 때)

관련 법률·시행령·시행규칙 현행 전문에서 '조례' 위임 조문과 주제 낱말 조문을 모두 뽑아 읽는다.

| 판정 | 기준 | 처리 |
|---|---|---|
| 위임 근거 없음 확인 | 의무·제한을 정하라고 맡긴 조문이 법률·시행령·시행규칙 어디에도 없음 | '위반 소지'로 올림 |
| 위임 범위 확인 필요 | 일반 위임만 있거나, 법률이 정한 범위를 조례가 넘는지 원문 비교가 더 필요함 | 참고에 확인 사항을 붙임 |
| 위임 조문 확인 | 법률이 직접 정한 의무를 옮겨 적었거나, 위임 조문이 있거나, 보조금 교부 조건·공공시설 이용 조건·위탁 계약 의무·지원 신청 요건처럼 받아들인 사람에게만 적용됨 | 참고(정비 대상 아님) |

## 5. 별표·규칙·미제정 대조

| 점검 | 후보가 되는 조건 |
|---|---|
| 별표 대조 | 자치법규 별표의 금액·요율·기준이 상위 시행령·시행규칙 별표의 상한·범위를 넘거나, 폐지·개정 전 기준을 그대로 씀 |
| 규칙 재위임 | ① 규칙이 사용료 금액을 정하는데 모조례에 상한·범위·산정 기준이 없음(「지방자치법」 제156조제1항, 법제처 의견13-0283·26-0099) — 아무것도 없으면 위반 소지, 고려 요소만 있으면 정비 권고 ② 과태료 대상 구역의 범위(거리)나 법률이 조례로 정하게 한 기준을 규칙이 정함(대법원 2020추5169, 의견23-0199) — 정비 권고(법률 직접 위임 사항이면 위반 소지) |
| 위임 조례 미제정 | 법령이 '조례로 정한다'(의무형)로 맡겼는데 해당 지자체에 그 법령을 인용하거나 같은 주제인 자치법규가 없음. 선택형·조건부('두는 경우')·다른 지역·교육감 소관은 뺌 |

## 6. 운영자 표본 확인 방법

후보 하나마다 다음 셋을 보고 맞음/틀림을 적는다.

1. **사실**: 카드의 '걸린 구절'이 자치법규 원문에 그대로 있는가
2. **근거**: '근거' 칸의 법령 조문·판례·법제처 사례가 실제로 그 내용인가(링크 확인)
3. **수준**: 위 3절 기준으로 위반 소지/정비 권고/규제 개선 권고가 맞는가 — 낮춰야 하면 '참고'

틀린 것은 이유(사실 오류 / 근거 오류 / 수준 과대)를 함께 적으면 규칙을 고친다. 정확도가 80% 아래인 점검 유형은 사이트에서 숨긴다.
