# 다잇다 데스크톱·한글(HWP) 업무 흐름 UI 개선 프롬프트 (운영자 요청 2026-10-06 — 작성만)

> 아래 블록을 그대로 디자인·프런트엔드 작업 세션에 넣는다. 1차·2차 개선(docs/design/ui-upgrade-2026-10.md)이 끝난 상태가 출발점이다. 사이트 현황 숫자는 2026-10-06 빌드 기준.

---

# 역할
너는 공공기관 업무 시스템(온나라·e호조·KOSIS 등)의 데스크톱 UI 를 설계해 본 시니어 프로덕트 디자이너 겸 프런트엔드 리드다. 대구 공무원용 산업·기업 자료 사이트 **다잇다**(daitda.co.kr, Astro 정적 사이트, 서버 없음)를 **데스크톱(1280~1920px)에서 표·자료를 꺼내 쓰는 공무원**의 관점에서 다시 설계하라. 핵심 사용자는 과장·주무관이며, 산출물은 대부분 **한글(HWP) 문서**(보고서·공문·의회 자료·보도자료·예산 설명자료)다. 결과물은 ① 업무 흐름(JTBD) 분석 ② 데스크톱 레이아웃·데이터 그리드 명세 ③ 「한글로 가져가기」 기능 명세와 호환성 시험 매트릭스 ④ 구현 계획·수용 기준이며, 코드는 토큰·컴포넌트·클립보드 페이로드 명세까지만 쓴다.

# 지켜야 할 제약
- 공공서비스 톤(큰 글씨 18px 기본, 최소 14px, 장식·그림자·다크모드 없음), 주색 하나(`#1B4F9B`), 증감에 빨강·초록 금지. 평가·순위·추천 표현 금지 — **정렬은 사용자가 하는 작업이지 사이트가 매기는 순위가 아니다**(정렬 상태를 저장·공유해도 '상위'·'TOP' 라벨을 붙이지 않는다). 특정 기업 부각 금지(전수 원칙).
- 정적 사이트·브라우저 안 처리(서버·AI 호출 없음), CSS 프레임워크 추가 금지, 토큰 체계(`tokens.css` v2)·`table.data-table` 규약·표 도구(`src/scripts/table_tools.ts`)는 유지하고 확장한다.
- 출처·기준일은 어떤 복사·내려받기에도 반드시 따라간다. 대표자 등 개인정보 열은 어떤 경로로도 나가지 않는다.
- 한글(HWPX) 파일 직접 생성은 2026-10-01 한글에서 깨져 내렸다(`src/scripts/hwpx.ts` 보류, 리포트용 `scripts/hwpx_report.py` 만 유지). **HWPX 재도입은 호환성 시험을 통과한 뒤에만** 제안한다.

# 현재 상태(출발점)
- 표: `table.data-table` 아래 「한글 표 복사」(클립보드에 `text/html` 표 — `border=1`, 맑은 고딕 10pt, 숫자 오른쪽 정렬 — 와 `text/plain` TSV 를 함께 넣음)·「PDF 내려받기」(pdf-lib, Pretendard 내장). 좁은 화면 카드 전환·열 우선순위·첫 열 고정·`tabular-nums`·행 호버는 2차에서 넣음. 열 선택·틀 고정(머리 고정)·단위 환산·소수 자릿수 통일·다중 표 묶음 복사는 없음.
- 그래프: 빌드 때 만든 인라인 SVG(넓은 판·좁은 판) + 표 JSON(`Chart.astro`, `src/generated/charts/`). 탐색(/explore/)은 CSV·PNG·TSV 복사 단추가 있으나 통계 페이지 그래프는 복사·저장 단추가 없다.
- 레이아웃: 본문 폭 `--measure-wide 1080px`(표·현황), 글 720px. 1440~1920px 화면에서 좌우가 비고 넓은 표는 가로 스크롤.
- 문서 산출: 기업 페이지 「기업 카드 PDF」·「인쇄」(print CSS: 표 도구 숨김, thead 반복), 지침 검토기 「검토 의견서 PDF」, 리포트 Word(.docx)·PDF·MD(/policy/). 공문·보고서용 **개조식 문장**은 어디서도 만들어 주지 않는다.
- 상호작용: 표 안 검색·셀 복사·열 숨김·정렬 상태 공유 링크 없음. 성장 계산기만 입력값 링크·A/B 저장·한 쪽 요약 PDF 가 있다. 키보드 단축키 없음.
- 측정 기준(2차 CI `ui_audit.yml`): axe 위반 0, 모바일 Lighthouse 접근성 100, 성능 73~97, CLS 0.007~0.183.

# 요구 산출물

## 1. 업무 흐름(JTBD)과 과업 분석
공무원이 이 사이트에서 자료를 꺼내 쓰는 대표 과업 6개를 **Jobs-to-be-Done** 형식("…할 때 …해서 …하고 싶다")으로 쓰고, 과업마다 현재 클릭 수·창 전환 수·수작업(서식 맞추기, 단위 바꾸기, 출처 적기)을 세어 **과업 흐름도(task flow)** 로 그린다:
① 산업별 기업 수·고용 표를 보고서 본문 표로 ② 특정 기업의 개요·지원 이력·재무를 검토 보고서 '붙임'으로 ③ 월간 경제지표를 의회·간부 보고용 한 장으로 ④ 지원사업 수혜 기업 명단을 공문 첨부 표로 ⑤ 성장 계산기 시나리오를 정책 설명자료 표·그림으로 ⑥ 사업 지침 검토표를 정산 검토 의견서로. 각 과업의 **최종 문서 형식**(한글 표 규격: 글꼴 맑은 고딕/함초롬돋움 10pt, 머리 음영, 테두리 0.12mm, 숫자 오른쪽·천 단위 구분, 단위 표기 위치, '자료: …' 줄)을 함께 정의한다.

## 2. 데스크톱 레이아웃과 데이터 그리드
- **반응형 상향(desktop-up)**: 1280/1440/1680/1920 브레이크포인트에서 본문 폭 1080 → 1280 → 1440(표 페이지만), 좌우 **여백 대신 사이드 레일**(목차·필터·요약 카드)을 두는 2단(2-column) 또는 3단 그리드 제안. 글(리포트) 페이지는 측정 폭(measure) 60~75자 유지.
- **데이터 그리드 컴포넌트** 명세(기존 `table.data-table` 확장, 가상 스크롤 없이 정적 DOM 유지):
  - 틀 고정: 머리 행 sticky(페이지 스크롤 기준 — 현재 `.scroll-x` 안이라 안 되는 문제의 해법: 표 높이 제한 + 안쪽 스크롤 또는 머리 행 복제), 첫 열 고정(있음), 머리 두 줄(colspan) 표도 고정 가능하게.
  - 열 선택기(column picker, 체크 목록·'기본으로')와 열 폭 끌기, 열 숨김 상태를 URL 인자(`?cols=`)로 공유.
  - 정렬: 열 머리 클릭 1·2·3회(오름·내림·해제), 다중 정렬(Shift), 정렬 상태 URL 공유. 화면에 '순위'·'TOP' 금지, 순번 열은 '번호'로.
  - 숫자 서식 제어: 단위 환산 토글(원 ↔ 천원 ↔ 백만원 ↔ 억원), 소수 자릿수(0·1·2), 음수 표기(− 또는 괄호), 천 단위 구분 — 모두 복사·PDF·CSV 에 그대로 반영.
  - 표 안 검색·하이라이트, 행 체크(선택 행만 복사), 셀 하나 복사(값만), 합계 행 고정(tfoot sticky).
  - 밀도 토글(comfortable 10px / compact 6px / dense 4px, 14px 글자 하한 유지), 줄무늬(zebra) 옵션.
  - 머리 셀 툴팁(지표 정의·단위·출처·기준일), 캡션 `<caption>` 표준화(표 번호·제목·단위·기준일·출처 한 줄).
- **그래프 패널**: 통계 페이지 모든 SVG 에 「PNG 저장(2배·3배)」「SVG 저장」「표로 보기」「그래프 복사(이미지)」 단추. PNG 는 흰 바탕·범례·출처 줄 포함, 한글 본문 폭(150mm) 기준 해상도.
- **키보드·포커스**: 표 셀 화살표 이동, `Ctrl+C` 로 선택 셀/행 복사, `/` 로 표 안 검색, `?` 단축키 안내. 데스크톱 호버 툴팁은 포커스로도 열림.
- **인쇄 CSS**: A4 세로·가로 자동(열 수 기준), 머리 행 반복, 표 도구·내비 숨김, 출처·URL·날짜 바닥글, 페이지 넘김 제어(`break-inside: avoid` 행 단위).

## 3. 「한글로 가져가기」 기능 명세 (핵심)
한글(HWP 2018/2020/2022/2024, 한컴오피스 Web)과 워드·엑셀에서 **붙여넣었을 때 표가 그대로 서는 것**을 1순위 품질 기준으로 두고, 다음을 명세한다:
- **클립보드 페이로드 설계**: `text/html` 표의 구조·스타일 규약(인라인 스타일만, `border-collapse`, `colgroup`/`width` 로 열 폭, `rowspan`/`colspan` 보존, `th` 음영, 숫자 셀 `text-align:right`, `mso-number-format`·`white-space:nowrap` 같은 호환 속성의 효과 검증), `text/plain` TSV(엑셀·메모용), 가능하면 `text/rtf`(한글이 RTF 를 더 안정적으로 읽는지 시험). 글꼴은 '맑은 고딕' 10pt 기본에 '함초롬돋움' 대안 설정.
- **복사 단추 묶음**: 「한글 표 복사」(기본) · 「선택 행만」 · 「머리 없이」 · 「제목·출처 줄 포함」(표 위 '표 N. 제목(단위, 기준일)'·아래 '자료: 기관, URL, 받은 날짜' 문단을 같이 넣음) · 「표 여러 개 한 번에」(페이지의 체크한 표를 순서대로) · 「개조식 요약 문장 복사」(표 값을 그대로 옮긴 사실 문장 3~5줄 — "대구 제조업 기업 수 4,318곳, 고용 34,862명(2026-08, 국민연금 가입자 기준)" 식, 평가·해석 없음).
- **문서 꾸러미 내려받기**: 기업 카드·지원 이력·재무를 **'붙임' 규격**(제목·표·출처·작성일)으로 한 번에 — PDF(현행) + **Word(.docx)**(`src/lib/docx.ts` 재사용, 한글에서 '워드 문서 열기'가 가장 안정적인 경로인지 시험) + 선택적으로 HWPX(시험 통과 시).
- **HWPX 재도입 시험 매트릭스**: OWPML(KS X 6101) 준수 여부, 한글 2018/2020/2022/2024·한컴오피스 Web 에서 열림/표 테두리/글꼴/병합 셀/줄바꿈/그림 삽입 6개 항목 × 표 유형 4개(단순·머리 두 줄·병합·긴 표)로 시험하고, 실패 항목이 있으면 도입하지 않는다. 시험 파일은 `public/hwpx/test/` 에 두고 결과를 `docs/design/hwpx-compat.md` 에 남긴다.
- **그림 가져가기**: 그래프 PNG(300dpi 상당)·SVG 를 한글 '그림 넣기'로 붙일 때 폭·캡션 규칙, '그림 N. 제목 — 자료: …' 캡션 문장을 클립보드에 함께.
- **한글 작업자용 안내**: 붙여넣기 뒤 '표 속성 → 글자처럼 취급', '셀 테두리 0.12mm' 같은 마무리 3단계를 도움말 패널로. 붙여넣기 실패 시 대체 경로(워드 거쳐 가기, TSV → 표로 변환) 안내.

## 4. 디자인 시스템 확장(토큰·컴포넌트)
- 토큰: 데스크톱 폭 `--measure-desk 1280/1440`, 그리드 밀도 3단계, 사이드 레일 폭, 툴팁·팝오버 토큰, 선택 행 배경(`--selected-bg`, 주색의 8% 틴트), 고정 머리 그림자 없이 구분선.
- 컴포넌트(해부·상태·ARIA): 데이터 그리드, 열 선택기(`menu`/`menuitemcheckbox`), 정렬 머리(`aria-sort`), 툴바(복사 묶음은 `menu` 버튼), 토스트(복사 결과·실패 원인), 단위 토글(세그먼트 컨트롤, `radiogroup`), 그래프 패널 툴바, 붙임 꾸러미 다이얼로그(`dialog`), 단축키 안내(`dialog`), 사이드 레일 목차(`nav` + 현재 절 하이라이트).
- 인쇄·PDF 템플릿: 표 PDF 에 캡션·출처·쪽 번호·가로 모드 자동.

## 5. 구현 계획·수용 기준
- 순서: 클립보드 페이로드 개선(가장 큰 효과, 작은 변경) → 복사 단추 묶음·캡션 표준 → 그래프 저장 → 데이터 그리드(틀 고정·열 선택·정렬·단위) → 데스크톱 레이아웃(사이드 레일) → 붙임 꾸러미(docx) → HWPX 시험.
- 회귀 위험: 표 도구가 모든 `table.data-table` 에 붙으므로 그리드 기능은 **opt-in 속성**(`data-grid`)으로 켠다. 검색 색인·PDF·인쇄 CSS·카드 전환(600px 아래)과 충돌 없게.
- 수용 기준: ① 한글 2020·2022·2024 에서 「한글 표 복사」 붙여넣기 6항목(테두리·병합·글꼴·정렬·열 폭·줄바꿈) 100% 보존(시험 매트릭스 기록) ② 과업 6개의 클릭 수 50% 이상 감소(흐름도 전후 비교) ③ 1440px 에서 넓은 표(25열)가 가로 스크롤 없이 또는 틀 고정으로 읽힘 ④ 키보드만으로 정렬·열 선택·복사 가능 ⑤ axe 위반 0, 접근성 100 유지, CLS < 0.1(표 도구 자리 선점) ⑥ 모든 복사·내려받기에 출처·기준일 포함, 개인정보 열 0건(자동 검사).
- 측정: Playwright 로 클립보드 HTML 을 받아 LibreOffice(또는 한컴오피스 Web)로 열어 셀 수·병합·테두리를 자동 대조하는 시험 스크립트 개요, Before/After 스크린샷 체크리스트(1440·1920 × 과업 6개).

# 출력 형식
마크다운. 1절 JTBD 표·흐름도 → 2절 그리드 명세(기능·상태·단축키 표) → 3절 클립보드 페이로드 예시(HTML 조각 포함)·복사 단추 표·HWPX 시험 매트릭스 → 4절 토큰·컴포넌트 표 → 5절 계획·수용 기준 → '하지 않을 것' 목록(순위 라벨, 서버 처리, 개인정보 열, 평가 문장 생성). 전문 용어는 처음 나올 때 한 줄 풀이. 근거는 측정값(클릭 수·픽셀·보존 항목 수)으로.
