# 지자체 부가가치세 최소화 — 시스템 업그레이드 프롬프트

> 2026-11-05 운영자 요청: '니가 달성군이 납부해야 할 부가가치세액을 최대한 줄여야 하는 대한민국 최고의 회계법인 담당자라면 지금 시스템을 업그레이드할 프롬프트를 만들어. 신고하는 공무원도 쉽게 쓸 수 있어야 되고, 공무원이 해야 할 일은 최대한 줄여야 돼.'
> 실행은 운영자 지시가 있을 때. 한 지자체를 완전히 검증한 뒤 다음 지자체로 넘어간다(달성군 → 수성구 → …). 신뢰가 가장 중요하다.

## 역할

너는 두 사람이다.
- **① 지방자치단체 부가가치세를 20년 넘게 맡아 온 대형 회계법인 파트너.** 목표는 달성군이 법대로 낼 세금만 내게 하는 것이다. 지난 5년 덜 공제받은 것은 돌려받고, 앞으로의 신고에서는 공제를 빠짐없이 받는다. 공격적 해석은 하지 않는다. 조문·유권해석·판례로 설명되지 않는 금액은 '판단 필요'로 남기고 질의서를 붙인다.
- **② 공무원 업무 시스템을 설계해 온 UI/UX 설계자.** 신고 공무원이 하는 일을 '파일 놓기 + 예/아니오 몇 번'으로 줄인다.

판정 규칙(`data/vat/rules.yml`, `judge`)은 조문 대조 없이 바꾸지 않는다. 바꿀 때는 조문·유권해석을 함께 붙이고 수용 시험을 더한다.

## 공무원이 하는 일 (이것보다 늘어나면 실패)

1. 점검기에서 기관을 고른다(1번).
2. 홈택스에서 파일 3종을 내려받아 한 칸에 놓는다(5년치 한꺼번에).
   - 지난 신고서 PDF(신고내역 조회)
   - 공제받지 못할 매입세액 명세서
   - 전자세금계산서 목록조회(매입) 엑셀
   - 사업용 카드 매입 엑셀은 있으면 함께
3. 시스템이 묻는 **확인 질문 10개 이하**에 예/아니오/모름으로 답한다. 질문은 돈이 큰 순서이고, 공개 자료로 답할 수 있는 것은 묻지 않는다.
   - 예: '교육문화복지센터 1층 카페는 돈을 받고 빌려주나요?'
   - 예: '화원명곡체육공원은 도시공원(체육공원)으로 결정된 곳인가요?'
4. 「경정청구 묶음」을 내려받아 홈택스 경정청구 화면에 그대로 옮긴다. 화면 칸별 입력값과 첨부 파일을 시스템이 준다.

나머지는 시스템이 한다. 담당자에게 시설 지정·공급자 분류·안분 계산·근거 찾기를 시키지 않는다.

## 시스템이 미리 해 둘 일 (지자체마다, 공개 자료로)

- **시설 사실 카드**(지자체 전체 시설). 시설마다 다음을 담는다.
  - 실체: 무슨 건물인지, 층별 용도, 준공 연도
  - 운영 주체: 직영 / 공단 대행 / 민간 위탁
  - 요금: 조례 별표·공단 요금표
  - 수입 귀속: 세입예산서 줄
  - 도시공원 결정 여부
  - 과세·면세 판정과 근거(조문·유권해석), 확인이 남은 사실
  - 출처는 조례·세입예산서·공단 누리집·군의회 회의록·보도이고, 모든 사실에 출처 URL을 단다(`data/vat/presets/<gov>.yml`).
- **공급자 → 시설 사전**
  - 나라장터 계약의 업체 사업자등록번호와 그 계약이 붙은 시설
  - 시설 이름 별칭
  - 세출 사업명 매핑표
  - 이것으로 홈택스 매입 목록의 대부분이 사람 손 없이 시설에 붙어야 한다(목표 90% 이상, 세액 기준).
- **기관 사업자등록번호**: 본청·사업장·공단(나라장터 수요기관정보).
- **같은 잘못의 실제 사례**: 경정청구 보도·권익위·정부합동감사·감사원(`data/vat/cases.yml` `mistakes`).

## 회계법인 관점 — 줄일 수 있는 길 (빠짐없이, 법대로)

1. **과세 시설 지출 공제 누락**(지난 5년 경정청구)
   - 체육·숙박·임대·음식·대관 시설의 신축·수선·운영 매입세액
   - 신고서 불공제 명세 '⑤ 면세사업등 관련'에 섞여 들어간 것부터 찾는다.
2. **세금계산서 누락**
   - 매입 목록 합 > 신고서 (16)이면 합계표에서 빠진 것이다.
   - 사업 부서가 회계 부서에 넘기지 않은 건립공사분이 대표적이다(창원시 합동감사).
3. **공통매입세액 안분 최적화**
   - 실지귀속(계량기·계약·면적)이 되는 것은 안분에서 빼 전액 공제한다.
   - 안분 생략 기준: 5만 원 미만, 또는 면세비율 5% 미만이고 500만 원 미만.
   - 총공급가액에 과세 매출을 빠짐없이 넣는다.
   - 면세공급가액에 넣을 것(면세사업 보조금)과 넣지 않을 것을 가른다.
   - 공급가액이 없는 고유사무는 매입가액·예정공급가액·예정사용면적 순으로 안분한다(영 제81조 제4항, 대법원 2017두55329).
   - 예정신고 → 확정신고 정산을 맞춘다.
4. **신축·대수선**
   - 예정사용면적 비율로 안분하고, 면적이 확정되는 과세기간에 정산한다(창원·세종 합동감사).
   - 큰 공사는 조기환급을 신청한다.
   - 면세 시설이 과세로 바뀌면 과세사업 전환 매입세액(영 제85조)을 공제한다.
5. **감가상각자산 재계산**: 면세비율이 5%p 넘게 바뀌면 재계산한다(영 제83조). 유리한 방향도 빠뜨리지 않는다.
6. **매출 쪽 과다 납부**
   - 면세인데 과세로 신고한 매출이 있는지 본다. 예: 체육공원 안 운동시설(재경부 부가가치세제과-306), 직영 주차장, 농기계 임대.
   - 매출세액 감소와 매입세액 불공제의 **순효과**를 시설마다 계산해 보여 준다. 판정은 법대로이고, 순효과는 결과로만 보여 준다.
7. **공단 대행 구조**
   - 대행사업비·수수료 면제(조특법 제106조 제1항 제6호)를 확인한다.
   - 군 명의 사업의 세금계산서는 군 등록번호로 받는다.
   - 공단 명의로 받은 것은 수정세금계산서 기한 안에 고친다.
8. **증빙·명의**
   - 다른 명의 세금계산서는 수정세금계산서 기한(1년) 안에 고친다.
   - 사업용 카드를 등록하고 카드 매입을 공제한다.
   - 지연 수취(2022-02-14 이전 공급분은 6개월)를 확인한다.
9. **가산세·환급가산금**
   - 수정신고·기한후신고는 일찍 낼수록 가산세 감면이 크다.
   - 경정청구 환급에는 국세환급가산금이 붙는다.
   - 돌려받은 돈은 바로 세입 처리한다(2025 대구 합동감사 지적).
10. **앞으로의 신고(매 분기)**
    - 같은 사전·규칙으로 신고 준비 숫자표를 만든다.
    - 다음 기에 놓치기 쉬운 것(재계산·정산·조기환급 시기)을 미리 알린다.

## 신뢰 장치 (금액을 보여 주기 전에)

- **대조 관문.** 올린 홈택스 파일이 그 기관의 신고와 맞는지 먼저 본다. 맞지 않으면 금액 대신 '무엇이 안 맞는지'를 보인다.
  - 매입 목록 세액 합과 신고서 (16)
  - 신고서 (16)−(17)과 (18)
  - 불공제 명세 합과 (17)
- **금액마다 출처 사슬.** 「파일 → 행 → 시설 → 판정 규칙 → 조문·유권해석」을 펼쳐 보이고, 엑셀·PDF 묶음에도 같은 열을 둔다.
- **세 칸으로만.**
  - 확정: 신고서·목록 숫자만으로 계산된 것
  - 자료를 내면: 무슨 자료인지 적는다
  - 판단 필요: 질의서 초안을 붙인다
  - 어림(계약금액 × 10/110 등)은 회색 참고로만 둔다.
- **사실 카드의 '확인 필요'는 질문으로 바뀌어 위 3단계에 나온다.** 답하면 판정과 금액이 그 자리에서 다시 계산된다.
- **지자체 단위 검증 완료 기준(달성군 먼저).**
  1. 실제 홈택스 파일 1년치로 대조 관문 통과(차이 0원)
  2. 시설 사실 카드 확인 필요 0건 또는 질문으로 남김
  3. 매입 목록 자동 귀속 세액 90% 이상
  4. 운영자가 결과표 확인 → 그다음 지자체

## 화면 원칙

- 첫 화면에는 '파일을 여기에' 한 칸과 금액 띠 하나만 둔다. 나머지는 접는다.
- 질문은 한 번에 하나씩, 현장 말로 묻는다. 각 질문 옆에 '이 답에 걸린 금액'을 보여 준다.
- 결과는 과세기간마다 「무엇이 틀렸나 → 고친 신고서 칸 → 돌려받는 돈 → 근거 → 같은 잘못의 실제 사례」로 보인다.
- 홈택스 경정청구 화면의 칸 순서대로 입력값표를 만들고, 붙일 파일 목록도 함께 준다.
- 모든 결과 화면 머리에 '판정은 참고이며 기관의 판단이 아닙니다'를 둔다. 평가·절세 홍보 문구는 쓰지 않는다. 담당자·대표자 이름과 전화는 싣지 않는다.

## 하지 않을 것

- 조문·유권해석 없는 공제, 공격적 해석, 홈택스 자동 로그인·크롤링, 서버로 파일 보내기.
- 공개되지 않은 내부 자료 수집.
- 추정 금액을 돌려받을 금액처럼 크게 보이기.

## 진행 순서 (커밋 단위)

1. **조사 — 지자체 사실 카드 완성(달성군).** 시설마다 실체·운영·요금·세입 귀속·도시공원 여부·판정·출처를 채운다(`presets/dalseong.yml`). 확인이 남은 사실은 질문 목록으로 만든다.
2. **설계.** 질문 엔진(사실 공백 → 질문, 걸린 금액 순), 대조 관문, 출처 사슬, 경정청구 화면 입력값표의 와이어프레임·문구·수용 기준을 `docs/design/vat-minimize.md`에 쓴다.
3. **구현(작은 커밋 여럿)**
   1. 대조 관문
   2. 질문 엔진과 즉시 재계산
   3. 공급자 → 시설 사전 자동 귀속 90%
   4. 매출 쪽 과다 납부와 순효과
   5. 경정청구 화면 입력값표·묶음
   6. 앞으로의 신고(분기 숫자표) 연결
4. **측정·시험.**
   - `scripts/vat_ux_test.mjs`에 달성군 시나리오를 더한다. 시나리오는 사실 카드, 고정 홈택스 파일(배치 본뜸·값 지어냄), 질문 답, 결과로 이어진다.
   - 수용 기준: 공무원 행동 수(파일 놓기 1 + 질문 ≤10 + 내려받기 1), 자동 귀속률, 대조 관문, 출처 사슬 완결.
   - before/after 표를 남기고, CLAUDE.md에 기록하고, 배포한다.
5. **운영자 검증.** 달성군 실제 파일로 한 번 돌려 차이를 고친 뒤 '검증 완료'를 기록한다. 그다음 수성구로 1~4를 되풀이한다.
