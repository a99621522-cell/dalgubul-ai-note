# 프롬프트 — 지난 신고서를 올리면 '무슨 자료를 더 올리면 얼마를 돌려받는지' 알려 주는 화면

> 사용법: 이 파일 전체를 Claude Code 세션에 붙여 넣고 "그대로 실행해". 저장소 `a99621522-cell/dalgubul-ai-note`, 점검기 사이트 https://vat-daitda.pages.dev/vat/ 기준.

---

## 0. 역할과 목표

너는 지자체 부가가치세 경정청구 실무를 아는 개발자다. 이미 있는 「지난 돈 돌려받기」(`/vat/review/`, `src/scripts/vat_review.ts`·`vat_review_pub.ts`)를 넓혀, **신고하는 공무원이 홈택스에서 받은 지난 신고 자료를 올리면** 화면이 다음 세 가지를 바로 보여 주게 만든다.

1. **지금 자료만으로 돌려받을 수 있는 금액**(확정에 가까운 몫)
2. **이 자료를 더 올리면 늘어나는 금액** — 자료마다 한 줄: "○○ 시설 계약서·검수조서를 올리면 +1,234,000원(2024년 제2기)"
3. **판단이 필요한 금액** — 유권해석·기관 판단이 있어야 정해지는 몫과 그 근거(조문·유권해석·질의서 초안)

모든 금액은 **가산세와 같이 드러나는 매출세액을 뺀 순액**도 함께 보인다(아래 3-4).

## 1. 지켜야 할 것 (어기면 안 됨)

- 파일은 **브라우저 안에서만** 읽는다. 서버·AI 호출 없음, 바깥 전송 없음(`src/scripts/vat_files.ts` 재사용). 홈택스에 대신 로그인하거나 자료를 긁어 오지 않는다(로그인 뒤 자료 수집 금지 원칙).
- **판정 규칙을 새로 만들지 않는다.** 판정은 `vat_rules.ts judge/toInput`, 근거는 `data/vat/rules.yml`(facilities·rulings·inquiries·admin_common·penalty)만 쓴다. 규칙을 고쳐야 하면 조문 원문(`data/guidelines/vat-*.txt.gz`, `national-tax-basic`)과 대조한 뒤 따로 커밋하고 그 사실을 보고한다.
- '확정'이라는 말은 쓰지 않는다. 화면 머리에 "판정은 참고이며 기관의 판단이 아닙니다". '절세'·'세금 아끼기'·평가 문구 없음.
- 기관 이름·금액·담당자 이름이 든 실제 파일은 저장소에 넣지 않는다. 시험 자료는 배치만 본뜨고 값은 지어낸다(`scripts/fixtures/hometax/` 처럼).

## 2. 입력 — 공무원이 홈택스·기관에서 받아 올 것

먼저 **실제 파일 배치를 확인**한다. 이 세션은 홈택스에 들어갈 수 없으니 ① 공개된 서식 원문(부가가치세법 시행규칙 별지 제21호 일반과세자 신고서·제22호 공제받지못할매입세액명세서·제39호(1) 매입처별 세금계산서합계표 — `data/guidelines/vat-rule.txt.gz`) ② 공개 학습 자료·예시 파일(러너 `site_probe.yml` file=true) ③ 운영자가 금액을 가린 실물을 올려 주면 그것으로 배치를 맞춘다. 확인하지 못한 배치는 "확인 필요"로 남기고 직접 입력 화면을 둔다.

| 기호 | 자료 | 받는 곳(메뉴 이름은 확인 뒤 `rules.yml sources_help` 에) | 읽을 것 |
|---|---|---|---|
| A | 지난 부가가치세 신고서(과세기간마다, PDF 또는 인쇄 화면) | 홈택스 신고내역 조회 | 등록번호·과세기간·신고 구분(예정/확정/기한후/수정), 칸 (1)~(30)·(36)~(56) 값 — 특히 매출 (1)(3)(4), 매입 (10)(11)(12)(13)(14)(15)(16)(17)(18), 불공제 (50)~(56) |
| B | 공제받지못할매입세액명세서(신고 첨부) | 같은 신고서 첨부 | 사유별 불공제 세액, 공통매입세액 안분(면세비율·기준), 정산·재계산 |
| C | 매입 전자세금계산서 목록(3개월씩 xlsx) | 홈택스 목록조회(매입) — 이미 읽음 | 건별 공급자·등록번호·공급가액·세액·품목·공급받는자 번호 |
| D | 사업용 신용카드 매입 내역 | 홈택스 사업용 신용카드 — 이미 읽음 | 건별·공제 여부 |
| E | (선택) 공개 지출 자료 | 점검기가 이미 가짐(`/vat-expense/`) | 세부사업·통계목·지출액 — 세금계산서가 빠진 사업 찾기 |
| F | (선택) 증빙 | 기관 문서 | 계약서·검수조서·면적표·사업자등록증·매출 신고 사실 — 올리면 '자료 있음'으로 바뀜(파일 내용은 읽지 않아도 됨, 이름·종류·대상 시설만 표시) |

A·B 를 읽는 파서는 `src/scripts/vat_filed.ts`(새 파일)로 만든다. PDF 는 pdfjs-dist(이미 의존성에 있음, `budget_check.ts` 참고)로 글자를 뽑아 칸 번호 `(nn)` 옆 숫자를 읽는다. 못 읽은 칸은 사람이 고칠 수 있는 입력 칸으로 보인다.

## 3. 계산 — '자료를 올리면 얼마' 엔진

과세기간 × 등록 단위마다 다음 네 갈래로 후보를 만들고, 후보마다 **상태 3가지**와 **필요한 자료 목록**을 붙인다.

### 3-1. 후보 갈래
1. **신고에 아예 안 들어간 세금계산서** — C 의 매입세액 합 − A 의 (10)+(11)+(12)+(13)+(14)+(15) 에 들어간 몫(공급자별로 맞출 수 없으면 기간 합으로). 귀속 시설이 과세면 후보.
2. **불공제로 처리된 것** — B 의 사유(면세사업 관련·공통 안분 등) 가운데, 귀속을 과세 시설로 바꾸거나 실지귀속으로 입증하면 공제되는 몫.
3. **공통 안분을 다시 하면 바뀌는 것** — 신고 때 면세비율·기준 대 `rules.yml admin_common`·영 제81조 기준으로 다시 계산한 비율의 차이(대법원 2017두55329 등 근거 표시).
4. **신고 안 한 과세기간** — 기한후신고(국세기본법 제45조의3), 경정청구가 아님을 표시.

### 3-2. 상태
- **지금 자료로 됨**: 귀속 시설이 과세로 설정돼 있고, 명의가 우리 등록번호이고, 증빙 칸이 채워짐.
- **자료를 올리면 됨**: 위 조건 가운데 빠진 것이 '자료'로 메울 수 있는 것. 빠진 것마다 자료 이름을 붙인다 — 예: 시설 귀속 증빙(계약서·검수조서·사업명), 시설 과세 근거(사업자등록·매출 신고 사실), 면적표(예정사용면적 안분), 공급가액 자료(면세비율), 수정세금계산서(다른 명의 — 기한 `fixDue` 표시), 종이 세금계산서 원본.
- **판단 필요**: 시설 유형이 '확인'(대관·광고 자리 등)이거나 본청 고유사무 안분처럼 유권해석이 걸린 것 — `rulingsHtml`·`inquiryHtml` 로 근거와 질의서 초안.

### 3-3. '자료를 올리면 +얼마' 표
자료 하나를 올렸을 때 상태가 바뀌는 후보들의 세액 합을 자료별로 모아, **늘어나는 금액이 큰 자료부터** 한 줄씩 보인다(순서는 금액순일 뿐 평가가 아님을 적음). 같은 자료가 여러 기간을 풀면 기간별로 펼친다. 자료를 올리면(F) 그 줄이 바로 '지금 자료로 됨'으로 옮겨지고 합계가 다시 계산된다.

### 3-4. 순액 — 같이 드러나는 것 빼기 (반드시)
- 매입세액을 공제받으려고 시설을 과세로 보면, 그 시설 **매출을 신고하지 않았던 기간에는 매출세액도 내야 한다**(수정신고). A 의 매출 칸에 그 시설 매출이 없으면 "이 시설 매출(사용료·대관료 등)이 신고에 없으면 매출세액 ○원과 가산세가 같이 생깁니다"를 보이고, 사용자가 그 기간 매출을 넣으면 순액을 다시 계산한다.
- 가산세는 `penaltyCalc`·`rules.penalty` 만 쓴다(합계표 미제출분 0.5% 등). 순액 = 후보 세액 − 같이 드러나는 매출세액 − 가산세 어림.
- 경정청구 기한(법정신고기한 + 5년, `claimPeriod`)을 넘긴 기간은 금액에서 빼고 "기한 지남 — 권익위 직권 시정 사례 참고"(cases.yml)로만 보인다.

## 4. 화면 (기존 화면을 넓힘)

`/vat/review/` 맨 위에 단계 셋:
1. **지난 신고 올리기** — A·B 파일 놓기(여러 기간 한꺼번에), 읽은 칸 표(고칠 수 있음), 신고 없는 기간 표시.
2. **매입 목록 올리기** — C·D(지금 화면 그대로), E 는 선택.
3. **결과** — 금액 카드 셋(지금 자료로 / 자료를 올리면 / 판단 필요) + 순액 + '자료를 올리면 +얼마' 표 + 기간별 표 + 근거 절(지금 `legalBasis()`) + 경정청구서 사유 초안·붙임 자료 zip(지금 기능 확장: 자료 목록·순액 계산 포함).

공무원 언어로 쓴다(칸 번호는 괄호로 함께). 키보드·스크린리더·인쇄는 기존 수준(`docs/design/vat-ux-spec.md`)을 지킨다.

5. 배포: main 에 합치면 `deploy_vat.yml` 이 시험 뒤 vat-daitda 에 올린다. `CLAUDE.md` 에 한 단락 기록.

## 6. 하지 않을 것

- 홈택스 화면을 흉내 내거나 전자신고 파일을 만들지 않는다.
- 환급을 장담하는 말, 금액 순위를 평가처럼 읽히게 하는 말을 쓰지 않는다.
- 유권해석이 걸린 몫을 '지금 자료로 됨'에 넣지 않는다.
- 실제 기관 신고서·금액을 저장소나 화면 예시에 넣지 않는다.
