# 프롬프트 — 수성구 담당자 맞춤 '지난 부가세 돌려받기'

> 쓰는 법: 이 파일 전체를 Claude Code 세션에 붙여 넣고 "그대로 실행해"라고 한다.
> 만든 날 2026-11-08. 대상 화면 https://vat-daitda.pages.dev/vat/review/?gov=suseong
> 선행: 담당자 확인 요청 `docs/drafts/수성구_부가세_돌려받기_담당자_확인요청_20261108.hwpx` — 회신이 있으면 0단계에서 먼저 반영한다.

---

## 0. 너의 역할과 목표

너는 지자체 부가세 경정청구를 여러 번 해 본 세무 실무자이자, 공공 서비스 화면을 설계하는 사람이다.
목표는 하나다 — **수성구 부가세 담당 공무원이 `?gov=suseong` 링크를 열고 지난 신고서를 올리면, 수성구에서 실제로 돈이 걸린 곳만 순서대로 보고, 확정 금액과 그 근거로 경정청구 자료를 받게 한다.**

**수성구만의 시스템이라도 따로 만든 화면이 아니다.** 같은 `/vat/review/` 한 화면에서 수성구 자료(설정 파일)가 순서·질문·안내를 바꾸게 한다. 다른 구·군도 나중에 설정 파일만 채우면 같은 수준이 되어야 한다. 화면을 늘리지 말고, 수성구에 맞지 않는 것을 숨기는 쪽을 먼저 고른다(운영자 2026-11-05 '다른 기능은 복잡해서 사용하기 힘들어').

## 1. 쓰는 사람

| | 수성구 부가세 담당 주무관 |
|---|---|
| 하는 일 | 구 본청 부가세 신고(직영 체육시설·야영장·주차장·청사 임대 등 과세 매출이 있는 기관) |
| 아는 것 | 홈택스에서 신고서 PDF 받기, 시설 이름과 담당 부서 |
| 모르는 것 | 어느 시설 공사비 부가세가 공제 대상인지, 복합 건물을 어떻게 나누는지, 경정청구서에 무엇을 적는지 |
| 불안 | 틀린 금액으로 청구했다가 감사 지적, 재단·위탁 시설 지출을 구 것으로 잘못 넣는 것 |

## 2. 수성구의 사실 (지금까지 조사한 것 — 회신으로 고친다)

| 사실 | 근거 | 화면에 주는 뜻 |
|---|---|---|
| 시설관리공단이 없다 | 2024 재정공시·자치법규·나라장터 수요기관정보 | '공단 대행' 갈래와 조특법 대행 면제 안내를 수성구에서는 숨긴다 |
| 체육시설은 구 직영, 사용료가 '부가가치세를 포함한 금액'(체육시설 조례 별표 3) | 조례 원문 | **과세 매출을 신고해 온 시설**이므로, 그 시설의 공사·운영비 매입세액을 공제했는지가 1순위 |
| (재)수성문화재단이 아트피아·구립도서관 12곳·생활문화센터를 자기 이름으로 운영 | 재단 누리집, 구의회 회의록 | 재단 명의 지출은 구 신고에 넣지 않는다. 구가 직접 낸 그 건물 공사비는 면세·행정(공제 없음)으로 본다 |
| 민간위탁: 화랑공원 테니스장·알파시티 축구장(수성구체육회, 수입 10% 위탁관리 수수료), 청소년수련시설·복지관 | 회의록, 조례 | 수수료가 구의 과세 매출인지가 질문. 수탁자 명의 지출은 제외 |
| 진밭골 야영장 사용료 2026 세입 약 2.9억 원 | 2026 세입예산서 | 야영장은 숙박 성격이라 과세. 매출 신고 여부와 시설 공사비 공제가 함께 걸린다 |
| 유료 공영주차장은 주차장특별회계 | 세입예산서, 주차장 조례 별표 3 | 직영이면 면세. 관리수탁자가 계약금액을 먼저 내고 요금을 거두는 곳은 임대 성격이라 따로 묻는다 |
| 복합 건물: 수성행복드림센터(반다비체육센터 포함, 연면적 7,319㎡), 구청사(은행 대부·충전소 부지·부설 주차장), 수성못(광장 점용·거리가게) | 조례·보도·세입예산서 | 과세 몫(share)이 금액을 크게 바꾼다. 지금 값(30%·2%·10%)은 추정 |
| 본청 사업자등록번호 502-83-02507 | 나라장터 | 시설별 사업장 등록 여부는 모름 — 등록 전 매입 불공제(법 제39조 제1항 제8호)와 바로 이어진다 |
| 공개 자료: 2026 세입예산서 853줄, 나라장터 계약 7,069건(2020-07~2026-11), 지방재정365 세부사업 연간 지출(2021~2025) | `data/vat/` | 주민참여 재정 포털 건별 지출은 해외 IP 차단으로 없음 — 국내 PC 몫 |
| 실제 홈택스 신고서로는 시험하지 않음 | — | 칸 읽기 실패를 화면이 분명히 알려야 한다 |

## 3. 바꾸면 안 되는 것

- 판정 규칙·계산(`vat_rules.ts judge`, `vat_diag.ts`, `vat_unlock.ts`, `vat_refund.ts` 의 금액 식, `rules.yml`)은 조문 근거 없이 바꾸지 않는다. 수성구 때문에 규칙이 바뀌어야 하면 조문·유권해석을 원문으로 대조한 뒤 `rules.yml` 에 넣고, 다른 지자체 금액이 바뀌는지 시험으로 확인한다.
- 달성군 고정 자료(`dalseong5y`) 확정 460,000원·최대 5,200,000원, 기존 수용 시험 전부 그대로.
- 서버·AI 호출 없음, 파일은 브라우저 안에서만. 모든 결과에 '판정은 참고이며 기관의 판단이 아닙니다'. 평가·절세 문구, 담당자 이름·전화 없음. 다잇다 사이트와 서로 링크하지 않음.
- 배포는 `/vat/review/` 한 화면(`deploy_vat.yml`).

## 4. 하는 순서

### 0단계 — 담당자 회신 반영
회신(맞음·틀림·모름, 신고서, 결과 갈무리)이 있으면 `data/vat/presets/suseong.yml` 을 고치고, 질문마다 `answered: 담당자 회신(날짜)` 을 단다. 회신이 없으면 지금 기본값을 쓰되 **추정인 값은 화면에 '추정'으로 보이게** 하고 다음 단계로 간다. 회신 내용 가운데 개인 이름·전화·내부 문서는 저장하지 않는다.

### 1단계 — 수성구 프로필을 설정으로
`data/vat/govs.yml` 의 수성구에 화면을 바꾸는 값을 둔다(코드에 '수성구' 글자를 박지 않는다).
- `hide`: 수성구에 없는 갈래(공단 대행·조특법 대행 면제 안내 등)
- `first`: 먼저 볼 시설 묶음과 그 이유 한 줄(과세 매출을 신고해 온 직영 체육시설 → 야영장 → 복합 건물 → 주차장)
- `exclude_payee`: 구 신고에 넣지 않을 명의(수성문화재단·수탁자) — 매입 목록·계약에서 이 명의 지출을 '구 신고 아님'으로 접는다
- `asks`: 질문 순서 고정 상한 3개, 나머지는 '더 정확히(선택)'
같은 키를 달성군에도 채워 달성군 화면이 바뀌지 않는지 확인한다.

### 2단계 — '수성구에서 먼저 볼 곳' 한 상자
결과 문장 바로 아래, 신고서를 올리기 전에도 보이는 상자 하나: 시설 묶음 4개 × (왜 돈이 걸리나 · 지금 자료로 본 어림 · 무엇을 올리면 확정되나). 어림은 회색, 확정은 신고서를 올린 뒤에만 굵게. 묶음을 누르면 그 시설의 계약·지출만 거른 목록으로 간다. 새 계산 없이 이미 있는 `contractsCtx`·`refundCalc` 값을 시설 묶음으로 모은다.

### 3단계 — 복합 건물 나누기(면적 표)
행복드림센터·구청사·수성못마다 '전체 면적 / 과세로 쓰는 면적'(또는 공급가액) 두 칸만 받아 share 를 계산하고(영 제81조 제4항, 대법원 2017두55329 — 원신고가 공급가액 비율이었는지 함께 묻기), 바뀐 금액을 바로 보인다. 근거 서류(건축물대장·임대차계약서·사용허가서)를 칸 옆에 적는다. 값은 설정(answers)에 남아 다음 기에도 쓴다.

### 4단계 — 명의 가르기
매입 목록·나라장터 계약에서 공급받는자 번호가 구 번호가 아니거나 계약기관이 재단·수탁자인 건을 '구 신고 아님(재단·수탁자 명의)'으로 따로 접고 합계만 보인다. 구 번호로 받았지만 재단 운영 시설에 쓴 지출은 '면세·행정 — 공제 없음, 이유: 시설 운영 수입이 재단 것'으로 표시한다. 잘못 넣으면 감사 지적이라는 점을 한 줄로.

### 5단계 — 실제 신고서 시험
담당자가 준 신고서(없으면 운영자에게 받은 것)를 `scripts/fixtures/hometax/suseong/` 에 **값을 지어낸 같은 배치**로 옮겨 고정 자료를 만든다(실제 금액·번호는 저장소에 넣지 않는다 — 공개 저장소). 칸 읽기가 틀리면 `vat_unlock.ts` 판독기를 고치고, 못 읽은 칸은 화면에 '이 칸을 못 읽었습니다 — 직접 적기'로 남긴다. 수용 시험 `SU1~` 를 더한다.

### 6단계 — 수성구 경정청구 묶음
기존 묶음에 수성구 시설 묶음별 시트(시설 · 과세기간 · 공급자 · 세액 · 근거 · 확인 서류)와 '구 신고 아님' 목록을 더한다. 경정청구서 사유 초안에 수성구 사실(직영 체육시설 사용료 과세 신고, 조례 별표 3 문구)을 근거로 넣는다. 결재용 Word 는 묶음 안에만.

### 7단계 — 측정·문서·배포
`?gov=suseong` 로 과업 4개를 재어 `docs/design/vat-suseong-before.tsv`·`after.tsv`:
A 링크 열기 → 신고서 올리기 → 확정 금액 / B 먼저 볼 묶음 하나의 이유와 근거 조문 / C 복합 건물 면적 넣고 바뀐 금액 / D 묶음 받기.
`docs/design/vat-suseong.md`(무엇을 설정으로 뺐나, 숨긴 것, 회신 반영 내역), CLAUDE.md 한 단락, `govs.yml` 수성구 상태를 근거에 맞게('담당자 확인 일부' 등). main 과 지정 브랜치에 푸시, 배포 확인.

## 5. 수용 기준

| 기준 | 목표 |
|---|---|
| 수성구 전용 코드 | 0줄 — 수성구 차이는 모두 `govs.yml`·`presets/suseong.yml` 에 |
| 숨김 | 수성구 화면에 공단 대행·조특법 대행 면제 안내가 안 보임, 달성군 화면에는 그대로 |
| 먼저 볼 곳 | 신고서 전 1366×768 첫 화면 안에 묶음 4개, 묶음마다 이유 한 줄 |
| 명의 | 재단·수탁자 명의 건이 공제 후보 금액에 0원으로 들어감(시험으로 확인) |
| 복합 건물 | 면적 두 칸 → share·금액이 바로 바뀌고 새로고침 뒤에도 남음 |
| 추정 표시 | 담당자가 답하지 않은 값은 모두 '추정' 표시 |
| 신고서 | 수성구 고정 자료로 확정 금액이 나오고, 못 읽은 칸은 화면에 이름이 나옴 |
| 기존 | 달성군 460,000 / 5,200,000 그대로, 기존 수용 시험 전부 통과, axe 0, 390px 가로 스크롤 없음 |

## 6. 하지 말 것

- 수성구용 새 페이지·새 메뉴를 만들지 않는다.
- 공개 자료에 없는 수성구 사실을 만들지 않는다. 모르면 질문으로 남기고 기본값은 돌려받을 금액을 적게 잡는 쪽.
- 담당자 회신의 실제 금액·내부 문서를 저장소에 넣지 않는다.
- 계약 어림(15.6억 원 같은 값)을 '돌려받을 금액'처럼 굵게 보이지 않는다.
- 운영자에게 확인 질문을 하지 말고, 갈리면 위 원칙 순서대로 정하고 문서에 이유를 적는다.
