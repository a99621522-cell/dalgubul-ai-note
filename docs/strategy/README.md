# docs/strategy — 산업별 전략 문서

격주 정책제안 리포트 루틴(docs/ROUTINE_PROMPT.md)이 기준 문서로 삼는 곳. 산업별 전략 문서(대구 산업분야별 전략과 정책)를 여기에 둔다.
아직 문서가 없다. 파일 이름 예: `mobility-auto-parts.md`, `robot-machinery.md`, `semiconductor.md`, `manufacturing-ax.md`, `healthcare.md`, `ai-sw-startup.md`.

`proposals/` — 리포트마다 7절(제안)만 따로 저장한 것. 전략 문서 갱신 재료.
