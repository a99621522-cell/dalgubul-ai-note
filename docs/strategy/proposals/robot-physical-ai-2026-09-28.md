# 정책 제안 — 로봇·피지컬AI (2026-09-28, 인사이트 리포트 형식)

출처·근거 절은 src/content/posts/2026-09-28-policy-robot-physical-ai-data.md. 연계 사업의 수행기관·공고 대조 결과는 docs/strategy/proposals/linked-programs-2026-09-28.md. 전략 문서 갱신 재료.

## 정책 제안: 현장 20곳, 거점 추가, 실증 20쌍

### 제안 1 (시) — 산단 공장 20곳을 제조 행동 데이터 학습 현장으로 지정하고 표준계약 1종

**문제는 로봇 121곳 중 1~9인 61곳이 학습할 현장이 없고, 현장이 될 271곳에는 데이터를 내줄 규칙이 없다는 것이다.** 대구의 로봇 시설 3곳은 시험과 개발 용도이고 가동 공정에서 데이터를 남기는 지정 현장은 0곳이다. 원인은 로봇 기업이 다품종 소량이라 자체 라인을 가질 수 없고(지난 회차 9월 26일), 271곳은 완성차·기계 협력사라 공정 데이터가 납품처 기밀과 얽혀 소유·이용 규칙 없이는 문을 열 수 없는 구조에 있으며, 산업연구원(9월 15일)이 교두보로 꼽은 행동 학습의 데이터원이 바로 이 공정이다.

**시가 2027년 상반기까지 50~299인 공장 271곳 가운데 20곳을 제조 행동 데이터 학습 현장으로 지정하고 데이터 권리 표준계약 1종을 두는 것을 제안한다.** 표준계약에는 데이터의 공장 소유, 로봇 기업 121곳의 학습 이용권과 기간, 납품처 기밀 항목 제외, 작업자 동의와 직무 전환, 성과 배분 5개 조항을 넣고, 카메라·센서·기계 ID 는 시가 지원하되 로봇 도입은 기업 선택으로 둔다. 추진은 2026년 11~12월 표준계약 마련과 271곳 공모, 2027년 1~3월 성서·국가산단·테크노폴리스 우선으로 20곳 지정과 로봇 기업 이용 신청, 4~9월 수집·학습 1차와 데이터셋 5종 공개, 10~12월 데이터셋 10종과 2028년 40곳 확대 결정 순서다. 연계할 사업은 대구시·대구기계부품연구원의 첨단로봇 요소 기술 공동연구개발 지원 과제(7월 1일 모집, 대구 소재 로봇 기업 주관, 수요처 연계 실증 포함)와 신규인 스마트공장(기초) 구축 지원·로봇산업기술혁신센터 조성 지원(공고 미확인)이며, 필요한 결정은 표준계약 고시 1건과 지정 공고 1건이다.

**검토한 다른 수단 2개는 택하지 않았다.** 로봇 기업에 자체 학습 랩 보조금을 주는 안은 1~9인 61곳에 랩을 둘 공정이 없어 데이터가 생기지 않는다. 테스트필드 안에 모의 공장을 만드는 안은 실제 공정의 편차가 없어 후학습 데이터로 쓰기 어렵고 2027년 시범운용 일정과 겹친다. 대상 규모는 자동차·부품과 기계·금속 그룹 50~299인 271곳(기업 사전 2026-08)이고 지정은 20곳, 이용 기업은 로봇 그룹 121곳이다. 1년 뒤 지표는 2027년 말 지정 현장 20곳, 공개 데이터셋 10종, 로봇 기업 이용 30곳, 현장 20곳의 고용 변화 공개 1회다.

### 제안 2 (정부 건의) — 피지컬 AI 지역거점에 대구 산단 데이터 수집 거점 추가와 기계 ID·행동 데이터 표준

**문제는 9월 22일 지역거점 구조가 전북·경북·경남 3개 도로 짜였고 로봇 행동 데이터의 형식·기계 ID 표준이 국내에 없다는 것이다.** 포럼의 협약 당사자는 3개 도와 금융기관들이었고(EBN 9월 22일, 요지), 일본은 AIST 가 표준화 주체를 맡았지만(9월 21일, 요지) 한국의 정부 사업 19건 가운데 데이터 표준을 이름에 단 과제는 1건뿐이고, 피지컬 AI 데이터·플랫폼 과제 3건은 전북·경남·기업 컨소시엄으로 수행 주체가 정해져 대구가 들어갈 공고가 2026년에는 없다. 원인은 메가프로젝트가 양산·실증 거점을 도 단위로 정하면서 '데이터가 나오는 공정'을 거점의 요건으로 두지 않은 구조에 있고, 대구 271곳은 도 단위 명단에 들어갈 통로가 없다.

**시가 2026년 11월까지 과학기술정보통신부·산업통상부에 3가지를 건의하는 것을 제안한다.** 첫째, 피지컬 AI 지역거점 실행계획에 대구 산단 학습 현장 20곳을 '제조 행동 데이터 수집 거점'으로 추가하고 경북 거점과 연계할 것, 둘째, 전북이 수행하는 SW플랫폼 사업의 제조·물류 실증 과제와 2028년 이후 선도기술개발 후속 공고에 대구 지정 현장 20곳을 행동 데이터원으로 연계할 것, 셋째, 기계 ID 와 행동 데이터 형식의 국가 표준 초안을 산업AI용데이터전처리자동화기술개발 과제와 잇도록 할 것이다. 추진은 2026년 10월 271곳 수요조사, 11월 건의서, 2027년 상반기 실행계획 반영 확인, 하반기 공고 확인 순서이며, 필요한 결정은 건의서 1건과 경북과의 공동 건의 여부 1건이다.

**대안으로 검토한 시 단독 표준과 새만금 위탁은 택하지 않았다.** 시 단독 데이터 표준은 완성차·로봇 기업의 전국 규격과 충돌해 로봇 121곳이 두 형식을 유지해야 하고, 새만금 양산 파운드리에 데이터 수집을 맡기는 안은 대구 271곳의 공정 데이터가 지역 밖으로 나가 표준계약의 공장 소유 원칙과 맞지 않는다. 대상 규모는 로봇 121곳과 부품 품목 73곳, 학습 현장 271곳(기업 사전 2026-08)이다. 1년 뒤 지표는 2027년 실행계획에 대구 수집 거점 문구 1건, 표준 초안 1건, 지역지정 과제의 대구 데이터셋 과제 3건이다.

### 제안 3 (기업·기관) — 자동차부품사와 로봇 기업의 실증 짝 20쌍

**문제는 8월 26일 간담회에서 부품 기업이 요구한 실증 기회·판로·인력 3가지에 답할 상시 구조가 없다는 것이다.** 참석 기업의 요구는 실증 기회 확보, 판로·시장 정보, R&D·전문 인력 연계였다(진흥원 보도자료, 매일신문 8월 27일 요지). 원인은 자동차·부품 50~299인 134곳이 로봇 기업 121곳과 거래선이 없고, 진흥원장이 9월 7일 제안한 설계 단계 부품 협의체(뉴데일리 9월 8일)도 아직 구성되지 않았으며, 지난 회차(9월 26일)의 부품·가공 풀 603곳 등록 전이라 누가 누구와 실증할지 볼 목록이 없기 때문이다.

**대구TP·한국로봇산업진흥원·대구기계부품연구원 3개 기관이 2027년 안에 자동차부품사와 로봇 기업의 실증 짝 20쌍을 맺는 것을 제안한다.** 한 쌍은 부품사 공장 1곳(제안 1의 지정 현장 우선)과 로봇 기업 1곳으로, 로봇 기업은 로봇과 학습을, 부품사는 현장과 작업 데이터를 내고 부품 품목 73곳에 드는 부품사는 로봇용 부품 공급 후보로 함께 검토한다. 추진은 2026년 12월 3개 기관 협약과 공고, 2027년 3월 1차 10쌍, 9월 2차 10쌍, 12월 실증 보고서 20건 공개 순서이며, 연계할 사업은 한국로봇산업진흥원의 첨단제조로봇 실증사업(3월 13일 공고, 공정모델형 등 3유형), 로봇산업기술개발(R&D)(2차 공고 9월 11일 마감), 국가로봇테스트필드(2027년 시범운용)다. 필요한 결정은 협약 1건과 공개 항목(대표자 제외) 결정 1건이다.

**매칭 상담회만 여는 안과 부품사 단독 로봇 도입 보조는 택하지 않았다.** 연 1~2회 상담회는 데이터가 남지 않아 산업연구원이 말한 행동 학습으로 이어지지 않고, 부품사가 각자 로봇을 사는 보조는 로봇 기업 121곳의 학습·검증 실적이 되지 않는다. 대상 규모는 자동차·부품 50~299인 134곳과 로봇 121곳, 우선 부품 품목 73곳(기업 사전 2026-08)이고 목표는 20쌍이다. 1년 뒤 지표는 2027년 협약 20쌍, 실증 보고서 공개 20건, 로봇용 부품 첫 납품 10건, 로봇 기업의 미국 외 수출 실적 제출 5곳이다.
