# 정책 제안 — 로봇·피지컬AI 휴머노이드 공공 파운드리 (2026-09-29, 브리프 형식)

출처·근거 절은 src/content/posts/2026-09-29-policy-robot-physical-ai.md. 전략 문서 갱신 재료.

## 3. 제안

### 제안 1. '부품 시제→성능·신뢰성 평가→안전인증' 한 경로 창구 — 검증 데이터 묶음 만들기

- **목표:** 대구 부품 기업(자동차·부품 972곳, 기어·동력전달 50곳, 전동기 45곳, 측정·제어기기 177곳)이 휴머노이드 핵심부품 국산화 과제·완제품사 공급망에 진입 — 지표는 휴머노이드 부품 과제 참여·납품 기업 수(지금 지원 이력상 0건 → N곳, N 은 조사 뒤 정함) [4][22] (기업 사전 2026-08)
- **진단:** 로봇 R&D 과제 참여 대구 기업 34곳 중 자동차·부품 3곳·부품 업종 1곳, 휴머노이드 관련 과제 0건, 생산품 '휴머노이드' 0곳 (지원 이력, 기업 사전 2026-08); 기업 건의는 성능을 입증할 실증 기회 [12]
- **원인:** 완제품사는 사용 이력·검증 데이터 없는 부품을 채택하지 않고 [18], 휴머노이드 부품은 평가 기준이 정립되지 않았으며 [13], 사양을 설계 단계부터 함께 정하지 않으면 채택되지 않음 [20] — 판로·인력보다 이 원인을 고른 이유는 검증 데이터를 만드는 시설이 대구에 있기 때문 [13][15][16]
- **기제:** 시제(DMI R&D)→성능·신뢰성 평가(진흥원 부품 실증, KTL·KETI)→안전인증(안전인증센터) 결과를 한 묶음의 검증 데이터로 만들어 완제품사가 요구하는 사용 이력·검증 데이터 [18] 를 대체·보완, 이 과정에 완제품사가 설계 단계부터 참여하면 사양 공동 결정 [20] 까지 충족. 대구의 비교우위는 세 시설이 모두 대구에 있고 모집단 972곳 중 669곳이 달서·달성에 있다는 점 (기업 사전 2026-08) [13][15][16]. 보조금은 기업 건의가 실증 '기회'라 원인을 없애지 못하고 [12], 완제품 파운드리 신설은 외주 수요 자료가 없으며 새만금·포항이 생산을 맡는 제약 조건 [1][23], 양산은 민간 완제품사의 결정 [22]
- **기대효과:** 검증 데이터 묶음을 갖춘 부품 건수가 늘면 완제품사의 채택 조건 [18][22] 을 충족하는 대구 부품이 생겨 과제 참여·납품 기업 수가 0에서 늘어남; 효과 크기는 조사 뒤 [12]
- **내용:** 대구시(기계로봇과)·한국로봇산업진흥원·DMI가 요소기술 공동 R&D, 부품 실증사업, 안전인증센터를 하나의 신청 창구로 묶고, 신청 부품마다 '시제→평가→인증' 3단계 결과와 완제품사 사양 검토를 한 묶음의 검증 데이터로 발급. 자동차부품 기업이 건의한 실증 기회 [12] 를 이 경로의 실증 단계에 배정. 연계 사업은 '기계로봇산업 육성'·'휴머노이드 로봇 안전인증센터 구축'·'로봇산업기술개발(R&D)' (사업 DB)
- **근거:** 2절 진단 1·2와 원인 [12][13][18][20], 시설 3곳 [13][15][16], 정부 국산화 목표 [4], 완제품사 채택 방침 [22][24]
- **수치 근거:** 대상 모집단 972·50·45·177·121곳은 기업 사전 2026-08 필터 값, 과제 참여 34·3·1·0은 지원 이력 값 [기업 사전]. 연간 처리 건수 N 은 조사 뒤 정함(부품 실증사업·안전인증센터 연간 용량 공개 뒤)
- **추진:** 2026-12 3자 창구 운영 합의와 공고, 2027-03 1차 접수(요소기술 R&D 2027년 과제·부품 실증사업 일정에 맞춤), 2027 하반기 안전인증센터 평가 항목과 연결하고 완제품사 사양 검토 참여 협약, 2028 정규 운영 여부와 완제품 파운드리 신설 검토(외주 수요 조사 결과로). 필요한 결정은 3자 협약과 창구 공고
- **대상:** 기업 사전 자동차·부품 그룹 972곳, KSIC 29142·28111·2721 업종 272곳, 로봇 그룹 121곳(조건: 산업 그룹·업종) 가운데 신청 기업, 신청 수 N 은 조사 뒤 정함 (기업 사전 2026-08)
- **대안:** 기업별 시제품 보조금(원인을 없애지 못함 [12][18]), 대구 완제품 파운드리 신설(수요 자료 없음, 새만금·포항 제약 [1][23]), 대경권 공동기획단 역할 분담 합의(검증 데이터가 없으면 분담을 정해도 대구 부품이 채택될 근거가 없음 [18]) 은 검토했으나 지금은 택하지 않음
