# 정책 제안 — 로봇·피지컬AI 특집: 공공 로봇 파운드리 (2026-09-26)

출처·근거 절은 src/content/posts/2026-09-26-policy-robot-physical-ai-foundry.md. 정기 회차와 별도의 특집. 전략 문서 갱신 재료.

### 제안 1 (시) — 테스트필드·안전인증센터 옆 '공공 로봇 파운드리(시제·파일럿 센터)' 조성
- 문제: 설계형 34곳·218명과 50인 미만 로봇 기업 74곳이 시제 수십~수백 대를 조립·시험할 시설이 없고, 공공 인프라 4곳은 시험·인증·R&D 기능. 국내 공공 시제 라인 0곳(3절).
- 분석: 원인은 로봇이 기종마다 공정이 바뀌는 다품종 소량이라 50인 미만 기업이 자체 라인을 갖기 어려운 구조이고(6절 생기원), 베이징·상하이는 이 구간을 공공 중시 플랫폼(설비 500대·연 2,000대)이 맡는다(4절 1~3). 대구는 만들 기업 2,118곳이 있어 시설 1곳만 빠졌다.
- 제안: 시가 테스트필드 부지(달성 테크노폴리스)에 기능 단위 6개의 센터 1곳 — ① DfM 설계 검토실 ② 부품 조달·지역 매칭(풀 603곳 견적) ③ 소량 조립 셀 6개 ④ 관절·모듈 조립·시험(액추에이터·감속기 시험대, 모터 다이나모, 배터리/BMS 시험, 하네스) ⑤ 완제품 조립·시험(캘리브레이션, EMC·안전 사전시험, 트레드밀, 온·습도 챔버, 데이터 수집실) ⑥ 민간 EMS 이관(도면·공정 카드 인계). 설비 기준은 베이징 4개 단위·상하이 ISO7 관절 라인·시험 400항목. 소유 시, 운영 한국로봇산업진흥원 또는 대구기계부품연구원 1곳, 이용료 원가 기준·50인 미만 감면, 기종당 상한 300대.
- 추진: 2027년 상반기 시 기본계획·운영기관 지정 → 하반기 장비 사양·이용 규정 고시 → 2028년 시범(설계형 34곳 우선) → 2029년 정규·EMS 3곳 이상 협약. 필요한 결정: 이용료·감면 조례, 운영기관 지정, 테스트필드 연계 협약 각 1건.
- 대안: ① 민간 EMS 위탁생산 보조금 — 택하지 않은 이유는 대구 로봇 기업의 위탁생산 사례가 0건이라 보조금이 흐를 거래선이 없어서. ② 테스트필드에 조립 기능만 추가 — 택하지 않은 이유는 조립 셀 6개·수집실이 인증 시험 공간과 겹치고 상하이도 훈련장과 중시 플랫폼을 건물 2개로 나눴기 때문.
- 근거: 3절 표, 4절 1~4, 5절 표, 6절 전체.
- 대상 규모: 이용 108곳(설계형 34곳+팩토리온 로봇 50인 미만 74곳, 기업 사전 2026-08), 공급 참여 603곳(부품 품목 ∪ 가공 업종, 10인 이상, 달성군 306곳 우선).
- 지표: 2028년 시제 100대·이용 20곳, 2029년 연 300대·이용 40곳·부품기업 참여 60곳·EMS 이관 10건.

### 제안 2 (정부 건의) — 새만금 양산 파운드리와 역할 분담, 대구를 '시제·파일럿·인증' 거점으로
- 문제: 새만금은 연 3만 대 양산·2029년 가동, 대경권은 '실증·부품기업 전환'으로만 적혀(6월 29일) 시제~양산 이전 구간을 맡는 지역이 없다. 3대 취약부품 국산화 사업(2027년 신설)의 시제 검증 장소도 미정.
- 분석: 원인은 메가프로젝트가 양산(새만금)과 실증(대경권)만 나누고 중시 단계를 정의하지 않은 구조이고(5절)(중국은 중시와 양산을 도시별로 나눔, 4절 1~3). 대구는 안전인증센터와 테스트필드가 한 부지라 시제→시험→인증을 1개 부지에서 잇는다.
- 제안: 시가 2026년 안에 산업통상부에 ① 대구를 '시제·파일럿·인증 거점'으로 메가프로젝트 실행계획에 명시 ② 액추에이터·로봇손·센서 국산화 사업의 시제 검증 장소로 대구 파운드리·DMI 지정 ③ 정부 구매 휴머노이드 250대의 출하 전 시험을 대구 안전인증센터에서 — 3가지를 건의.
- 추진: 2026년 11월 시 건의서(3절 숫자·5절 표 첨부) → 2027년 상반기 실행계획 반영 확인 → 하반기 국산화 사업 공고에 검증 장소 확인 → 2028년 정부 구매 250대 시험 협약. 필요한 결정: 실행계획 문구 1건, 시험 항목 협약 1건.
- 대안: ① 대구에도 양산 파운드리 유치 요구 — 택하지 않은 이유는 연 3만 대 양산이 새만금 1곳으로 정해졌고 대구 로봇 87곳 중 50인 미만 74곳이라 양산 수요가 없기 때문. ② 안전인증센터만 운영 — 택하지 않은 이유는 시제가 없으면 인증 이용 기업이 설계형 34곳에서 나오지 않기 때문.
- 근거: 4절 1~3, 5절 정부 사업·표, 6절 산업연구원.
- 대상 규모: 직접 121곳(로봇 그룹)+부품 품목 73곳, 시제 검증 우선 29곳(부품 중 10인 이상).
- 지표: 2027년 실행계획에 대구 역할 문구 1건, 국산화 사업 공고에 대구 검증 장소 1건, 대구 부품기업 참여 10곳.

### 제안 3 (기업·기관) — 부품·가공 풀 603곳 등록, 공정 데이터 표준화, EMS 연계 협약
- 문제: 만들 수 있는 기업 2,118곳(10인 이상 603곳)이 있어도 설계 기업이 '누가 어떤 공차로 며칠 안에 만드는지' 볼 목록이 없고, 대구 로봇 위탁생산 공개 사례 0건(3절).
- 분석: 원인은 부품·가공 기업이 자동차·기계 납품 구조라 로봇 설계 기업과 거래선이 없고, 설계형 34곳은 1~9인 18곳이라 조달 인력이 없는 구조. 상하이는 시험 400항목으로 부품 검증을 대신한다(4절 2).
- 제안: 대구기계부품연구원·대구테크노파크·한국로봇산업진흥원 3개 기관이 2027년 상반기까지 ① 풀 등록(설비·공차·재료·납기·월 생산능력 5항목 표준 카드, 603곳 초청) ② 견적·발주 데이터 표준 3종(도면·공정 카드·검사 성적서) ③ 민간 EMS 3곳 이상과 이관 협약(지역 부품기업 우선 견적 조항).
- 추진: 2026년 12월 3개 기관 협약 → 2027년 3월 표준 카드·모집 공고 → 6월 1차 등록 200곳 공개 → 하반기 EMS 협약 3건. 필요한 결정: 역할 분담 협약 1건, 공개 항목(대표자 제외) 결정 1건.
- 대안: ① 연 1~2회 매칭 상담회만 — 택하지 않은 이유는 603곳 상시 조달에 못 미치고 공정 데이터가 남지 않아서. ② 설비 목록 없는 디렉터리 — 택하지 않은 이유는 설계 기업에 필요한 것이 회사명이 아니라 공차·재료·납기 5항목이기 때문.
- 근거: 3절 표, 4절 2·5, 5절 표, 6절 산업연구원·IR협의회.
- 대상 규모: 등록 대상 603곳(부품 품목 73곳 ∪ 가공 업종 2,061곳 중 10인 이상, 기업 사전 2026-08), 수요 조사 34곳(설계형), 1차 목표 200곳.
- 지표: 1년 뒤 풀 등록 200곳(달성군 60곳 이상), EMS 협약 3건, 설계 기업 34곳 중 견적 요청 15곳, 로봇용 첫 납품 20곳.

2026-09-25 정기 리포트의 제안 1·2에 '시제를 만드는 자리' 1곳을 더한 것이며, 전략 문서(docs/strategy)에 로봇 문서가 없어 정합성 검토는 다음 회차에 한다.
