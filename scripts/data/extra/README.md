# extra — 산단 외 기업 목록 투입구

팩토리온(공장등록) 밖의 기업을 기업 DB에 넣는 곳. 여기에 CSV 를 두고 `python3 scripts/import_extra.py` 를 실행하면
`scripts/data/extra_companies.csv`(새 기업, id `x0001`~)와 `company_tags.csv`(이미 있는 기업의 태그)가 갱신된다.
전수 원칙: 목록의 모든 기업을 같은 형식으로. 대표자·연락처 열은 있어도 저장하지 않는다.

## 파일 형식
UTF-8(BOM 가능) 또는 cp949 CSV. 열 이름은 아래 표준 이름이나 괄호 안의 한글 이름 가운데 하나.

| 열 | 필수 | 설명 |
|---|---|---|
| name (회사명·기업명·업체명·사업장명) | ✔ | |
| address (주소·소재지) | ✔ | 대구 구·군이 주소에 있어야 한다(없는 행은 건너뜀) |
| sector_code (업종코드) | | KSIC 5자리. 없으면 업종명·사업내용 키워드로 산업 그룹 판정 |
| sector (업종·업종명) | | |
| product (생산품·주요제품·사업내용) | | |
| workers (종사자수·종업원수·고용인원·상시근로자수) | | 없으면 고용 집계 대상에서 빠진다 |
| founded (설립일·설립연도·창업일) | | 있으면 7년 이내 기업에 `startup` 태그가 자동으로 붙는다 |
| source (출처) | | 없으면 파일 이름 |
| as_of (기준일·기준월) | | 자료 기준일 (YYYY-MM) |
| tags (태그) | | `config/site_types.yml` 의 tags 키를 `;` 로 이어서. 예: `ccei;startup` |

입지 유형(수성알파시티·연구개발특구·지식산업센터·산업단지·개별입지)은 주소로 자동 판정된다(`config/site_types.yml`).

## 넣을 수 있는 공개 목록 (출처·기준일을 as_of·source 에 적을 것)
- **수성알파시티 입주기업**: 대구디지털혁신진흥원(DIP) 알파시티 입주기업 현황 / 공공데이터포털 "대구광역시_수성알파시티 입주기업" → 주소가 알파시티면 유형 자동
- **연구개발특구 연구소기업·첨단기술기업**: 연구개발특구진흥재단 공개 명단(대구특구) → `tags: labfirm`
- **대구창조경제혁신센터 보육·졸업기업**: 센터 홈페이지 공개 목록 → `tags: ccei`
- **지식산업센터 입주기업**: 팩토리온 지식산업센터 현황(건물·주소) + 건물별 입주기업 공개 목록 → 주소에 건물명이 있으면 유형 자동
- **벤처기업**: 벤처기업확인 공시(대구) → `tags: venture` / **이노비즈**: 이노비즈협회 공시 → `tags: innobiz`
- **국민연금 사업장(대구 전체)**: `data/nps/YYYYMM.csv`(build_stats.py 입력)와 같은 파일에서 팩토리온·위 목록에 없는 사업장을 뽑아 여기에 넣으면
  산단 밖 모든 고용 사업장이 들어온다. 이때 `workers` = 가입자수, `founded` = 적용일자

이 환경(claude.ai 클라우드 세션)은 위 포털 접속이 막혀 있어 파일은 사용자가 내려받아 두거나, 네트워크가 허용된 루틴이 받아 둔다.
