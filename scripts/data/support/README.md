# support — 지원사업 수혜 이력 투입구

대구시·중앙부처·기관 지원사업에서 지원받은 기업의 사업명·기관·연도·금액을 CSV 로 두고 `python3 scripts/import_support.py` 를 실행하면
`scripts/data/support_history.csv` 에 합쳐지고 기업 사전(기업 페이지 "지원사업 이력"), 통계(산업별 지원 기업 수·금액), 정책제안 리포트가 읽는다.
공개 자료만. 원문 URL·기준일 필수. 금액은 원문 값 그대로(단위 열에 원/천원/백만원). 평가·순위 없음.

## 파일 형식 (UTF-8 또는 cp949, 열 이름은 표준 이름이나 괄호 안 한글)

| 열 | 필수 | 설명 |
|---|---|---|
| name (기업명·회사명·수행기관·보조사업자) | ✔ | |
| program (사업명·과제명·보조사업명) | ✔ | |
| year (연도·선정연도) | ✔ | YYYY |
| funder (지원기관·부처·주관기관) | | 예: 산업통상부, 대구광역시, 대구테크노파크 |
| layer (구분·재원) | | 국비 / 시비 / 기관 |
| type (지원유형) | | R&D / 보조금 / 융자 / 바우처 / 선정 / 인증 |
| amount (금액·연구비·보조금액) | | 숫자만. 없으면 빈칸 |
| amount_unit (단위) | | 원 / 천원 / 백만원 (없으면 원) |
| address (주소·지역) | | 대구 구·군이 있으면 기업 매칭 정확도가 오른다 |
| source (출처), source_url (출처URL) | ✔ | |
| as_of (기준일) | | |

## 공개 자료로 채울 수 있는 것 / 없는 것

| 자료 | 내용 | 금액 | 받는 곳 |
|---|---|---|---|
| NTIS 국가R&D 과제 | 과제명·사업명·부처·수행기관(기업)·연구비·연도 | ✔ (정부출연금) | ntis.go.kr 과제 검색 → 수행기관 지역 '대구' → CSV 내려받기 (API 는 NTIS_KEY) |
| 대구시 지방보조금 공개 | 보조사업명·보조사업자·교부액·연도 | ✔ | 지방보조금관리시스템(보탬e) 정보공개, 대구시 재정공시 |
| 기관 선정 공고·보도자료 | 선정기업 명단·사업명(대구TP·DIP·창경센터·산단공 등) | 대개 없음(사업 총액만) | 기관 공고 게시판(주간 루틴이 inbox 에 넣는 공고문에서 명단 추출) |
| 기업마당·공공기관 공고 | 사업명·기관·기간 | 총액만 | 이미 data/notices/notices.csv |
| DART 공시(상장·공시대상) | 정부 보조금·연구개발비는 재무제표 주석 | 일부 | scripts/collect_dart_fin.py (매출액·영업이익, DART_KEY) |
| 중기부 정책자금·기보·신보 개별 기업 | 비공개 | ✗ | 통합관리시스템(SIMS)은 기업 동의 기반이라 개별 공개 없음 |

매출액은 DART 정기보고서를 내는 상장·공시대상 기업만 공개 자료가 있다(대구 소재 상장사 수십 곳). 외부감사 대상 비상장사의 감사보고서는 DART 에 있으나
API 로 매출 수치를 받지 못하므로 지금은 넣지 않는다. 비공개 기업의 매출은 싣지 않는다.
