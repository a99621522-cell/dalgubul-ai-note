## 1. 의료 AI 시장과 데이터의 중요성

- **세계 의료 AI 시장 2026년 367억 달러, 2031년 1,948억 달러 전망** [1]

- **진단:** 전국 보건의료 가명정보 결합·활용 3년 78건 [6], 대구 중개 포털 데이터 공급 병원 2곳 [27]
- **원인:** 병원은 정제 비용과 법적 위험을 지고 보상은 약한 인센티브 불일치 — 한국은행 분석(집필자 견해) [7]
- **기제:** 특구 실증특례로 특례 범위 안의 제공에 책임 범위와 책임보험을 정하면 병원이 지는 위험이 줄고, 대구는 로봇 글로벌혁신특구에서 개인정보보호법 특례를 운영한 선례 [35]와 상급종합병원 5곳이 한 협의체에 든 조건 [28]을 갖춤. 보조금만으로는 법적 위험이 줄지 않아 특례를 택함 [7]
- **기대효과:** 포털 데이터 공급 병원 수 증가(현재 2곳 [27], 협의체 전체 5곳 [28]) — 효과 크기는 조사 뒤 정함
- **내용:**
  - 대구시가 의료 데이터 제공 특례를 기존 로봇 글로벌혁신특구 계획 변경 또는 신규 특구 신청 가운데 하나로 추진, 경로는 중소벤처기업부 협의로 결정
  - 비조치의견서 제도 [11]를 보건의료 데이터 제공 병원 사례에 적용하고 사후 재식별 사고 때 책임 범위를 명시하는 규제개선 과제 제출
  - 상급종합병원 지정·의료질평가 기준에 데이터 제공 실적 항목이 있는지 확인한 뒤, 항목이 없으면 반영을 제도개선 과제로 제출
  - 시 협력사업(AI 바이오·메디시티대구 협업사업 지원) 참여 병원 선정 때 데이터 제공 실적 반영
- **근거:** 4절 문제 1, [6][7][11][35]
- **수치 근거:** 5곳은 [28], 2곳은 [27], 3곳 = 5 − 2; 목표 공급 병원 수와 데이터 건수 N 은 조사 뒤 정함
- **추진:** 2026년 4분기 협의체 병원 의견 수렴과 규제개선 과제 목록 작성, 2027년 상반기 특구 경로 결정·신청
- **대상:** 협의체 상급종합병원 5곳 [28], 데이터를 쓰는 의료용 기기 제조 122곳 (기업 사전 2026-08)
- **대안:** 병원별 보조금 대신 특례를 택한 이유 — 한국은행이 짚은 원인이 보상과 위험 두 가지이고 보조금은 위험 쪽을 줄이지 못함 [7]

### 방안 2. 협의체 공동 IRB·DRB 승인의 상호 인정

- **목표:** 대구 기업이 협의체 병원 여러 곳의 데이터를 요청할 때 심의를 한 번 받는 상태 [29][30]
- **진단:** 가명정보 결합 평균 310일 [11], 대구 협의체는 공동 IRB·DRB 표준 절차 협력을 시작한 단계 [30]
- **원인:** 다기관 데이터가 병원별 심의를 거치는 구조 — 복지부가 IRB·DRB 표준 운영절차와 공용 DRB 신설을 발표한 배경 [8]
- **기제:** 공동 심의 승인을 참여 병원이 인정하면 병원 수만큼 반복되던 심의가 1회로 줄고, 대구는 케이메디허브 공동 심의 실무 [29]와 KAIRB 통합심사 표준 절차 협력 [30], 상급종합병원 5곳이 든 협의체 [28]를 갖춰 시범 조건이 있음. 병원별 심의 인력 증원은 반복 구조를 바꾸지 못함 [8]
- **기대효과:** 다기관 요청의 심의 횟수가 병원 수에서 1회로 줄어듦 [8] — 기간 단축 폭은 조사 뒤 정함
- **내용:**
  - 협의체 공동 IRB·DRB 승인을 참여 병원이 인정하는 방식을 특구 실증 항목으로 넣거나 공용 DRB 운영 방안의 지역 연계 모델로 협의
  - 영상·텍스트 등 데이터 유형별 가명처리 기준(가이드라인 위험도 3단계 [11])에 법적 지위를 주는 규제개선 과제 제출
- **근거:** 4절 문제 2, [8][11][29][30]
- **수치 근거:** 310일은 [11], 5곳·14개 기관은 [28]; 단축 목표 일수 N 은 조사 뒤 정함
- **추진:** 2026년 4분기 협의체 공동 심의 규정 정비, 2027년 하반기 상호 인정 실증
- **대상:** 협의체 병원 5곳 [28], 의료용 기기 제조 122곳 (기업 사전 2026-08)
- **대안:** 기업이 병원별로 따로 심의받는 현행 방식 대비 — 심의 횟수가 병원 수에 비례 [8]

### 방안 3. 협의체 병원의 표준 전환 시범 참여

- **목표:** 협의체 병원 데이터가 같은 표준(KR CDI·KR Core, 공통데이터모델)으로 나와 여러 병원 데이터를 합쳐 쓸 수 있는 상태 [14]
- **진단:** 심평원 비정형 데이터 표준화 0.5% [10], 표준은 EMR 인증의 참조기준 단계 [14]
- **원인:** 표준 적용이 필수가 아닌 참조기준으로 운영되는 구조 [14]
- **기제:** 필수화 시범에 협의체 병원이 먼저 참여하면 기업마다 반복하던 변환 작업이 병원 단계에서 한 번으로 줄고, 대구는 이미 표준화된 질환 데이터 약 25만 건과 KTL 참여 중개 컨소시엄 [27]을 갖춰 새 데이터를 표준에 맞춰 쌓을 기반이 있음. 기업별 변환 지원은 같은 작업을 기업 수만큼 반복 [10]
- **기대효과:** 협의체 병원 간 데이터 결합에 드는 변환 작업 축소(표준화 0.5%인 공공 데이터와 대비 [10]) — 효과 크기는 조사 뒤 정함
- **내용:**
  - 협의체 병원의 KR CDI·KR Core 필수화 시범 참여와 공통데이터모델(CDM) 전환을 보건복지부·한국보건의료정보원과 협의
  - 미국 데이터 차단 금지 규제 [23]를 참고해 정당한 사유 없는 전송 거부·지연을 다루는 규정 검토를 규제개선 과제로 제출
- **근거:** 4절 문제 3, [10][14][23][27]
- **수치 근거:** 0.5%는 [10], 25만 건은 [27]; 전환 병원 수 N 은 협의체 협의 뒤 정함(최대 5곳 [28])
- **추진:** 2027년 협의체 병원 시범 참여 협의, 중개 사업 과제 공고에 표준 적용 항목 반영
- **대상:** 협의체 병원 5곳 [28], 의료용 기기 제조 122곳 (기업 사전 2026-08)
- **대안:** 국가 보건의료데이터 거점의 표준화를 기다리는 방법 대비 — 지역 병원 데이터에 적용되는 시점은 전략 일정에 달림 [9]

### 방안 4. DIP 개인정보 이노베이션 존을 반출 없는 의료 AI 학습 공간으로

- **목표:** 대구 기업이 원본 데이터를 병원 밖으로 옮기지 않고 AI를 학습·검증하는 상태 [12][13]
- **진단:** 주요 공공기관은 방문 이용만 허용하고 평일 근무시간에만 접근 가능 [10], 국립암센터 비정형 데이터는 내부 연구 참여 때만 이용 [10]
- **원인:** 반출 대신 방문 이용으로 제한하는 제공 방식 [10]
- **기제:** 이노베이션 존은 가명처리 수준 완화·다양한 결합키·장기 보관·영상 표본 시험이 가능한 공간이고 [12][13], 2026-08-20 국회를 통과한 개인정보보호법 개정안의 AI 원본 활용 특례 [13]와 연합학습(모델이 병원으로 가고 결과값만 모으는 방식)을 결합하면 반출 없이 학습 가능. 대구는 DIP가 이미 전국 10곳 중 1곳으로 지정됐고 [12], 수성알파시티 데이터안심구역 [31]과 AI 신약개발 거점 GPU [33]가 있어 새 공간을 짓는 것보다 절차가 짧음
- **기대효과:** 대구 기업의 의료 데이터 학습 과제가 방문 이용 제약 [10] 없이 진행 — 효과 크기는 조사 뒤 정함
- **내용:**
  - DIP 이노베이션 존에 협의체 병원 가명 데이터 반입과 연합학습 연결을 개인정보보호위원회·병원과 협의
  - 개정 개인정보보호법의 AI 원본 활용 특례 적용 절차를 의료 데이터 과제로 신청
  - 복지부 연합학습 시범모델(사업 DB 사업명) 확산 때 대구 협의체 병원 참여 협의, GPU는 AI 신약개발 거점 [33]과 연계해 기업 저가 이용 방안 마련
- **근거:** 4절 문제 4, [10][12][13][31][33]
- **수치 근거:** 10곳은 [12]; GPU 규모와 이용 기업 수 N 은 조사 뒤 정함
- **추진:** 2027년 상반기 이노베이션 존 의료 데이터 반입 협의, 특례 시행 일정에 맞춰 신청
- **대상:** 의료용 기기 제조 122곳, 그중 방사선·전기식 진단기기 12곳 (기업 사전 2026-08)
- **대안:** 새 안심 공간을 짓는 방법 대비 — 이미 지정된 DIP 존 활용이 지정 절차를 생략함 [12]

### 방안 5. (조사 방안) 대구 기업의 데이터 비용과 이용권 활용 실태

- **무엇을:** 대구 의료용 기기·의료 AI 기업의 데이터 정제·가명처리·결합 비용, 의료데이터 이용권(2026년 40과제 [8]) 신청·선정 현황, 협력 병원 확보 여부
- **왜:** 이용권은 40과제로 늘었고 [8] 추가 모집에 비수도권 의료기관 협력 가점이 있지만 [38], 대구 기업의 활용 규모를 보여 주는 공개 자료가 없어 비용 지원 방안의 크기를 정할 근거가 필요
- **누가·어떻게:** 대구시와 DIP가 중개 사업 참여 기업 [27], 케이메디허브 입주 기업, 의료용 기기 제조 122곳(기업 사전 2026-08)을 대상으로 설문·면담
- **근거:** 4절 문제 5, [8][37][38], 기업 사전 2026-08
- **추진:** 2026년 4분기 조사, 2027년 상반기 결과로 비용 지원 방안과 이익 환원 원칙(데이터 사용처 공개 등, 환자 인식 [37]) 결정
- **대상:** 의료용 기기 제조 122곳 (기업 사전 2026-08), 중개 사업 참여 기업 [27]
