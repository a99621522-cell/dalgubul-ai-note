## 요약

- **대구 '지역특화 제조데이터 활성화' 2차 컨설팅 모집(2026-10-14) — 대상(1차 기준)은 스마트공장을 구축한 기계요소·소재부품 기업** [1][2]
  - 1차는 15곳 안팎 선정, 선정 기업은 다음 해 AI 솔루션 실증 지원사업 참여 자격(요지) [2]
- **같은 기업군에 산업부 '제조 AI 데이터 밸류체인' — 자체 AI 도입이 어려운 중소 제조기업에 데이터 수집 장치 보급 계획(요지)** [4]
- **대구 가공 공정 업종(주조·단조·열처리·절삭가공·플라스틱제품) 등록 공장 988곳, 1~9인 645곳(65.3%), 산업단지 737곳** (기업 사전 2026-09)
- **문제 — 988곳 가운데 스마트공장·데이터 수집 설비를 갖춘 곳을 기업 단위로 알려 주는 공개 자료 없음, 두 사업 중 어느 경로에 맞는지 가를 기준 없음** (기업 사전 2026-09) [10]
- **제안 — 1차 컨설팅의 제조데이터 진단 항목을 공통 문항으로 988곳의 스마트공장·데이터 수집 상태를 단지·규모별로 세는 조사 1건** [2][4] (기업 사전 2026-09)

## 1. 배경

- **2026-10-14 중소벤처기업부 '지역특화 제조데이터 활성화 사업' 대구 2차 컨설팅 참여기업 모집, 마감 2026-10-29** [1]
  - 1차(2026-07-30 보도): 스마트공장을 구축한 대구 기계요소·소재부품 제조기업 15곳 안팎, 제조데이터 분석·AI 활용 방안·디지털 전환 전략 사전 컨설팅(요지) [2]
  - 선정 기업은 다음 해 AI 솔루션 실증 지원사업 참여 자격 — 컨설팅 → 실증 순서(요지) [2]
  - 2026-07-29 대구TP 성서캠퍼스에서 같은 사업 AI 솔루션 실증 선정기업 간담회(요지) [3]
- **산업부 '제조 AI 데이터 밸류체인 구축' 대구 선정(2026-05 보도) — 정밀가공·금형·열처리 등 지역 주력 제조업 대상(요지)** [4]
  - 제조 데이터 품질 평가·인증 플랫폼, 자체 AI 도입이 어려운 중소 제조기업에 데이터 수집 장치 보급 계획(요지) [4]
  - 대구기계부품연구원·서울대 산학협력단·한국전자기술연구원·한국섬유기계융합연구원 참여(요지) [4]
- **지역거점 AX 혁신 기술개발 — 2026-10-08부터 과제 공모, 신규 연구개발과제 21개(로봇 11·바이오 10) 지정공모(요지)** [5]
  - 과제 분야가 로봇·바이오라 가공 공정 수요 기업 대상 사업과는 갈래가 다름 [5]
- **연구기관 진단 — 현재 제조 AX 는 공장 안 고정설비 중심이라 비정형 업무·구형 설비에 한계** [6]
  - KIET 는 업종·공정별 제조 AX 로드맵과 산업단지 단위 AI 학습 인프라를 정책과제로 제시 [6]
  - KIET 2026-10-15 보고서는 피지컬 AI 병목으로 실제 현장 데이터(Real World Data)를 들고, 메모리 → 컴퓨팅 인프라 → 제조 데이터 → 피지컬 AI 로 잇는 경로를 제시 [7]
- **대경권 — 피지컬AI 노출도가 동남권과 함께 가장 높은 권역, AI준비도 순위는 대구 등 지방 대도시가 더 낮아짐(집필자 견해)** [8]
  - 취업자 직업 구성: 비수도권 장치·기계조작 12.0%·단순노무 14.6%, 수도권 8.1%·12.7% [8]
  - 정책 시사점으로 테크노센터 등 공공의 중개 역할을 듦 [8]
- **해외 — 영국 정부 'Made Smarter Adoption', 중소 제조기업에 전문가 조언·디지털 전환 로드맵·리더십 교육·보조금을 묶어 지원, 2022.4~2025.3 평가 2026-07-30 공개(요지)** [9]

- **대구 가공 공정 업종 등록 공장 988곳·종사자 신고 10,275명(937곳 집계)** (기업 사전 2026-09, 조건: 팩토리온 공장등록 대표 업종 KSIC 243·2591·25921·25924·222)

  - 규모: 1~9인 645(65.3%), 10~49인 262, 50~299인 30, 값 없음 51 (기업 사전 2026-09)
  - 입지: 성서지방산업단지 376, 대구제3일반산업단지 231, 개별입지 207, 달성일반 45, 달성2차 38 — 산업단지 합 737곳(74.6%) (기업 사전 2026-09)
  - 구·군: 달서구 385, 북구 331, 달성군 191, 서구 48, 군위군 18, 동구 15 (기업 사전 2026-09)

  - 원인은 조사 대상 — 스마트공장 구축·데이터 수집 설비가 공장등록·통계의 항목이 아님 (기업 사전 2026-09) [10]

## 3. 제안

전제(988곳의 스마트공장 구축·데이터 수집 상태)를 받칠 공개 자료가 없으므로 정책 제안 대신 조사 제안 1개만 둠.

### 조사 제안. 대구 가공 공정 988곳 데이터 수집 상태 기준선 조사

- **목표:** 제조AI센터 컨설팅·실증과 데이터 수집 장치 보급의 대상을 기업 상태에 맞게 나눌 기준값 — 988곳의 스마트공장 구축 여부·데이터 수집 설비 보유를 업종·단지·규모별로 센 분포표 1개, 목표값은 조사 뒤 정함 [2][4] (기업 사전 2026-09)
- **진단:** 컨설팅은 스마트공장 구축 기업 가운데 1회 15곳 안팎을 받고 [2], 장치 보급은 자체 AI 도입이 어려운 중소기업을 대상으로 하는데 [4], 대구 가공 공정 업종 988곳 가운데 1~9인이 645곳이고 이들의 스마트공장·데이터 상태는 공장등록·통계에 항목으로 없음 (기업 사전 2026-09) [10]
- **원인:** 원인은 조사 대상 — 공개 자료가 업종·종사자(공장등록)와 시도 중분류 집계(광업·제조업조사)만 담음 (기업 사전 2026-09) [10][11]
- **기제:** 같은 진단 문항으로 988곳을 세면 '스마트공장·데이터 있음' 기업은 컨설팅·실증 경로로, '수집 설비 없음' 기업은 수집 장치 보급 경로로 나눠 모집할 수 있음 [2][4]; 대구는 988곳 중 737곳이 산업단지에 있고 성서 376·제3 231곳으로 두 단지에 607곳(61.4%)이 모여 단지 단위 현장 조사·장치 보급 묶음이 쉬움 (기업 사전 2026-09); 산업단지 단위 접근은 KIET 정책과제와 같은 단위 [6]; 신청 기업 진단(현행)은 신청한 곳만 보여 모집단 분포를 주지 않음 [2]
- **기대효과:** 두 사업의 모집 대상이 기업 상태 분포에 맞춰지고, 같은 문항으로 해마다 다시 세면 '데이터 수집 설비 보유 기업 수'가 제조 AX 추적 지표가 됨 [2][4]; 효과 크기는 조사 뒤
- **내용:** 대구광역시(제조 AX 담당 부서)가 2026년 4분기~2027년 1분기에 ① 2차 컨설팅의 제조데이터 진단 항목을 공통 문항으로 정리 [1][2] ② 기업 사전 필터의 988곳에 짧은 설문과 단지별 현장 방문 — 스마트공장 구축 여부·수준, 설비별 데이터 수집(PLC·센서) 여부, 데이터 보관 기간, AI 도입 의향 ③ 업종·단지·규모별 집계만 공개(기업 이름 없음) ④ 결과를 제조AI센터 실증 모집과 데이터 밸류체인 장치 보급 대상 선정 기준으로 넘김 [3][4]
- **근거:** 1절 컨설팅 모집 [1][2]·실증 [3]·데이터 밸류체인 [4]·KIET [6][7]·한국은행 [8], 2절 988곳 (기업 사전 2026-09)·광업·제조업조사 [10][11]
- **수치 근거:** 988 = 44 + 153 + 66 + 449 + 276 (기업 사전 2026-09); 65.3% = 645 ÷ 988; 74.6% = 737 ÷ 988; 607 = 376 + 231, 61.4% = 607 ÷ 988; 15곳 안팎 [2]; 분포 목표값·장치 보급 기업 수·조사 표본 수는 조사 뒤 정함
- **추진:** 문항 정리(두 사업 주관기관과 협의) → 설문·현장 방문 → 업종·단지·규모별 집계표 → 2027년 실증·장치 보급 모집 공고에 반영. 필요한 결정: 두 사업 주관기관의 문항 공동 사용 합의, 공개 범위(집계만), 기존 컨설팅 진단 결과를 집계에 넣을지 여부
- **대상:** 기업 사전 필터 — 팩토리온 공장등록 대표 업종 KSIC 243·2591·25921·25924·222, 988곳 (기업 사전 2026-09)
- **대안:** 신청 기업만 진단(현행) — 신청 기업에 한정되어 모집단 분포 없음 [2]; 전국 실태조사의 지역 집계 — 대구 가공 공정 업종의 기업 단위 값 공개 없음; 수집 장치 일괄 보급 — 이미 스마트공장을 갖춘 기업과 겹칠 수 있음 [2][4]

## 4. 기대효과와 한계

- **기대효과(지표 형태)**
  - 대구 가공 공정 988곳의 스마트공장 구축·데이터 수집 설비 보유 분포표 1개 (조사 결과)
  - 제조AI센터 실증 모집과 데이터 수집 장치 보급 대상의 선정 기준 1개 [2][4]
  - 해마다 같은 문항으로 다시 세는 '데이터 수집 설비 보유 기업 수' 지표 (조사 결과)
- **한계·반론**
  - 응답률이 낮으면 분포가 응답 기업 쪽으로 기울 수 있음 — 1~9인 645곳은 응답 부담이 커 현장 방문 비중을 높여야 할 수 있음 (기업 사전 2026-09)
  - 업종 묶음은 이 브리프의 조작 정의 — 사출은 플라스틱제품(222) 안에 다른 품목과 섞여 있고, 금형(KSIC 29294)은 기업 사전 대표 업종으로 잡히지 않아 뺐으며, 부 업종으로 가공을 하는 공장은 빠짐 (기업 사전 2026-09)
  - 988곳은 공장등록 기록 수 — 한 회사의 여러 공장이 따로 셈해짐 (기업 사전 2026-09)
  - 기계장치 장부 잔액 감소(−3.0%)가 설비 연식이나 데이터 수집 가능성을 뜻하는지는 이 자료로 알 수 없음 [11]
  - 광업·제조업조사(10인 이상 사업체)와 기업 사전(모든 규모 공장 기록)은 기준이 달라 서로 견주지 않음 [10] (기업 사전 2026-09)
  - 2차 컨설팅 공고 원문(선정 규모·자격 세부)과 데이터 밸류체인의 장치 보급 대상·시기는 원문을 열지 못해 검색 요지로만 확인, 미확인 세부가 남음 [1][4]
  - 두 사업 주관기관이 이미 기업별 진단 자료를 갖고 있을 수 있음 — 그 경우 조사는 공개 집계로 묶는 일로 줄어듦
  - 영국 평가 보고서의 효과 수치는 읽지 못해 인용하지 않음 [9]
- 확인 상태: 기관 발간물 3건 [6][7][8]은 저장소 요지(1,500자)·전문 요약으로 확인 / 검색 요지 6건 [1][2][3][4][5][9]은 원문 대조 필요 / KOSIS 2표 [10][11]·기업 사전은 저장소 표를 직접 집계(docs/strategy/research/manufacturing-ax-data-baseline-2026-10-20.md)
